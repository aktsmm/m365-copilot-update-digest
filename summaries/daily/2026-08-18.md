### Microsoft 365 アプリ: Microsoft 365 Copilot アプリの新しい Copilot ノートブック デザイン

- 原題: Microsoft 365 app: New Copilot Notebooks design in the Microsoft 365 Copilot App
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/18
- リリース段階: Launched
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=562662

Microsoft 365 Copilot アプリの新しい Copilot ノートブック デザインにより、ユーザーは関連するチャット、出力作成、参照を永続的な AI ワークスペースに整理できるようになりました。 Copilot はノートブックに蓄積されたコンテキストを使用して応答をグラウンディングするため、作業は毎回最初からやり直すのではなく、セッションをまたいで継続されます。この間...

### OneDrive Web の Copilot によるファイルの機能の向上

- 原題: OneDrive: Improved capabilities for files with Copilot in OneDrive Web
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/18
- リリース段階: In development
- 役割タグ: 管理者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=569215

OneDrive の Copilot ファイル スキルが向上したため、チャットからファイルから直接完成した作業に進むことができます。 Copilot は、適切なコンテンツの検索、ファイルとデータの分析、要約、ダッシュボード、プレゼンテーションなどの洗練された出力の作成、OneDrive からの結果の保存または共有による共同作業に役立ちます。

- 原題: Microsoft Teams: Interactive Agents for Teams Meetings and Calls
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/18
- リリース段階: Retirement
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=490564

さらなる検討の結果、現時点ではこれを展開し続けることはできません。ご不便をおかけして申し訳ございません。 Teams 会議や 1 対 1 の通話に対話型エージェントを導入する新機能が導入されました。ゼロ状態プロンプトと履歴サポートにより、グループまたはプライベートでエージェントと対話し、シームレスな対話を実現します。

### 電子情報開示 - ユーザー所有の SharePoint 埋め込みコンテナをデータ ソースとして選択します

- 原題: Microsoft Purview: eDiscovery- Select user-owned SharePoint embedded container as a data source
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/18
- リリース段階: In development
- 役割タグ: 管理者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=569364

電子情報開示ユーザーは、選択したユーザーが所有または作成した SharePoint Embedded コンテンツ コンテナを表示および選択できるようになります。これらのコンテナーには、Microsoft Loop、Copilot Pages、Copilot ノートブック などのアプリのコンテンツが保存されます。
