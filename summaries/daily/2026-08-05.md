### Microsoft 365 Copilot アプリの簡素化された設計

- 原題: Microsoft Copilot (Microsoft 365): Simplified design for the Microsoft 365 Copilot app
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/05
- リリース段階: Launched
- 役割タグ: 管理者向け / 作成者向け

Microsoft 365 Copilot Web およびデスクトップ アプリのデザインが刷新されたことで、ユーザー エクスペリエンスが簡素化され、Copilot との連携が促進されます。これには、チャット ホーム画面、チャット応答レイアウト、ナビゲーション ペインの更新が含まれます。

### 研究者の批評

- 原題: Microsoft Copilot (Microsoft 365): Critique in Researcher
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/05
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=558538

回答は GPT とクロードが協力して生成されます。GPT が最初の回答の草案を作成し、クロードが回答の精度、完全性、引用の完全性を高めるためにレビューします。

### 強調表示された応答コンテンツについて Copilot に質問する

- 原題: Microsoft Copilot (Microsoft 365): Ask Copilot about highlighted response content
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/05
- リリース段階: In development
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=522616

応答から文、段落、または表を強調表示し、その選択部分のみを処理するように Copilot に依頼します。レビューしている正確な文章について、焦点を絞った説明、簡潔な要約、簡単な翻訳、または次のステップを入手できます。大まかな答えにこだわる必要はもうありません。選択内容はプロンプトでプレビューされるので、編集する前に編集できます。

### 研究者評議会

- 原題: Microsoft Copilot (Microsoft 365): Researcher Council
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/05
- リリース段階: In development
- 役割タグ: 作成者向け

Council in Researcher は、さまざまなプロバイダーの複数の主要な AI モデルを 1 か所で並行して実行するため、出力をすばやく比較し、コンセンサスと競合を確認して、ツールを切り替えることなく、より自信を持って一か八かの意思決定を行うことができます。

- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け

### Researcher の Copilot メモリ

- 原題: Microsoft Copilot (Microsoft 365): Copilot memory in Researcher
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/05
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
