## 全件

### Microsoft 365 Copilot でカスタム エンジン エージェントを利用可能に

- 原題: Microsoft Copilot (Microsoft 365): Copilot extensibility – Developers can build custom engine agents with the Microsoft 365 Agents SDK
- ソース: Microsoft 365 Roadmap
- 公開日: 2025/01/11
- リリース段階: In development
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=474445

開発者は、Microsoft 365 Agents SDK を使用してカスタム エンジン エージェントを作成できます。これらのエージェントは独自の AI スタック上に構築されており、Microsoft 365 Copilot、Micros... などのさまざまなプラットフォームに展開できます。

### Microsoft 365: Windows 上の Microsoft 365 アプリの設定を更新しました

- 原題: Microsoft 365: Updated settings for the Microsoft 365 app on Windows
- ソース: Microsoft 365 Roadmap
- 公開日: 2025/01/11
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=471004

Windows 上の Microsoft 365 アプリには、アプリをタスク バーにピン留めする設定が追加されました。
