### Microsoft Agent 365: エージェントのコントロール プレーン

- 原題: Microsoft Agent 365: the control plane for agents
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/29
- リリース段階: Launched
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=558448

エージェント 365 は、AI エージェントのコントロール プレーンです。これにより、IT 管理者とセキュリティ管理者は、Microsoft 365 および接続されたプラットフォーム全体でエージェントを大規模に監視、管理、保護できるようになります。

### Copilot Studio で作成者間のエージェント共有に対応

- 原題: Microsoft Copilot Studio: Agent Sharing amongst makers
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/29
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=569475

Copilot Studio の新しい GHCP ハーネスで、作成者間でエージェントを共有できるようになります。自動割り当てのセキュリティ ロールにより、他の作成者へ閲覧者または編集者としてアクセスを付与できます。

### Teams で AI 生成の会議アーカイブに対応

- 原題: Microsoft Teams: AI-generated meeting archive for knowledge retention
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/29
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=558933

管理者は、Copilot (およびファシリテーター) がトランスクリプトの保存期間を超えて会議からの重要な洞察を保持できるようにするテナント全体のポリシーを有効にすることができます。これにより、Copilot はトランスクリプトの有効期限が切れた後でも、過去の会議に関する質問に回答し続けることができます。管理者は、この AI によって生成された会議の継続時間を設定することもできます。

- 原題: Microsoft Teams: Unified Agent and App Installation Management Across Microsoft 365 and Teams Admin Center
- ソース: Microsoft 365 Roadmap

- リリース段階: Rolling out
- 役割タグ: 管理者向け / 作成者向け
