## 全件

### Teams で AI 生成の会議アーカイブに対応

- 原題: Microsoft Teams: AI-generated meeting archive for knowledge retention
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/07/31
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=558933

管理者は、Copilot (およびファシリテーター) がトランスクリプトの保存期間を超えて会議からの重要な洞察を保持できるようにするテナント全体のポリシーを有効にすることができます。これにより、Copilot はトランスクリプトの有効期限が切れた後でも、過去の会議に関する質問に回答し続けることができます。管理者は、この AI によって生成された会議の継続時間を設定することもできます。

### Microsoft Teams の Microsoft 365 管理エージェントを使用して SMB 管理タスクをより高速に実行します

- 原題: Microsoft Teams: Run SMB admin tasks faster with Microsoft 365 Admin Agent in Microsoft Teams
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/07/31
- リリース段階: Update
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=558255

現時点ではこの変更を進めないことを決定しました。ご不便をおかけして申し訳ございません。 SMB 管理者は、Microsoft Teams の Microsoft 365 管理エージェントを使用して、一般的な管理タスクを完了し、重要な設定アクションに関するガイダンスを得ることができます。管理エージェントは、管理者に代わってユーザーを追加し、ライセンスを割り当てることもできます。
