## 全件

### 埋め込み画像を使った応答精度向上に対応

- 原題: Microsoft Copilot (Microsoft 365): Now smarter with visuals: Copilot Chat leverages embedded images for richer, more accurate answers.
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/28
- リリース段階: Launched
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=560540

Copilot は、Word 文書 (.docx)、PowerPoint プレゼンテーション (.pptx)、PDF などのファイルに埋め込まれた画像を使用して応答を解釈し、グラウンディングするように強化されました。この機能により、Copilot はチャート、図、スクリーンショットなどの視覚要素から洞察を抽出できるようになり、答えがテキストだけではないことが保証されます。

### メーカー間でのエージェント共有

- 原題: Microsoft Copilot Studio: Agent Sharing amongst makers
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/28
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=569475

新しい GHCP ハーネスで他のメーカーとエージェントを共有できるようになります。メーカーは、自動割り当てされたセキュリティ ロールを使用して、他のメーカーのエージェント閲覧者 (分析/評価の表示のみ) または編集者 (表示、編集、構成、共有、公開) のエージェントへのアクセスを許可できます。

### Android 上の Teams Rooms でのファシリテーターとの対面会議用の AI を活用したメモ

- 原題: Microsoft Teams: AI-powered notes for in-person meetings with Facilitator in Teams Rooms on Android
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/28
- リリース段階: In development
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=560700

ファシリテーター エージェントは、スケジュールされた会議またはハイブリッド会議中にリアルタイムのメモや会議結果をキャプチャするだけでなく、Android 上の Teams Rooms での対面会議のメモ、意思決定、アクションを支援します。ルームコンソールをワンタップするだけでファシリテーターを招待できます。会議のメモが部屋の正面に表示されます...

### Microsoft 365 Copilot モバイル アプリのプロアクティブなプッシュ通知

- 原題: Microsoft Copilot (Microsoft 365): Proactive push notifications for the Microsoft 365 Copilot mobile app
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/28
- リリース段階: Update
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=560339

Microsoft 365 Copilot モバイル アプリは、「今日の概要」や「待機中のアイテム」などの一般的な生産性ワークフローのプッシュ通知を積極的に送信し、開くとユーザーにそれぞれの Copilot 応答を送信します。この機能は Copilot メモリを活用しており、Micro... を搭載したユーザーが利用できるようになります。
