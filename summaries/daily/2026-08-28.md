## 全件

### Copilot Chat で埋め込み画像を活用し、回答精度を向上

- 原題: Microsoft Copilot (Microsoft 365): Now smarter with visuals: Copilot Chat leverages embedded images for richer, more accurate answers.
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/28
- リリース段階: Launched
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=560540

Copilot Chat が Word、PowerPoint、PDF などのファイルに埋め込まれた画像を理解し、グラフ、図、スクリーンショットからも洞察を抽出できるようになります。画像を含む資料を根拠に、より豊富で正確な回答を生成できます。

### Copilot Studio で作成者間のエージェント共有に対応

- 原題: Microsoft Copilot Studio: Agent Sharing amongst makers
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/28
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=569475

Copilot Studio の新しい GHCP ハーネスで、作成者間でエージェントを共有できるようになります。自動割り当てのセキュリティ ロールにより、他の作成者へ閲覧者または編集者としてアクセスを付与できます。

### Microsoft 365 Copilot モバイル アプリでプロアクティブなプッシュ通知に対応

- 原題: Microsoft Copilot (Microsoft 365): Proactive push notifications for the Microsoft 365 Copilot mobile app
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/28
- リリース段階: Retirement
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=560339

Microsoft 365 Copilot モバイル アプリが、「今日の概要」や「対応待ちの項目」などの一般的な生産性ワークフローについてプロアクティブにプッシュ通知を送信します。通知を開くと、対応する Copilot の回答を確認できます。

### Teams Rooms on Android の対面会議で Facilitator の AI メモに対応

- 原題: Microsoft Teams: AI-powered notes for in-person meetings with Facilitator in Teams Rooms on Android
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/28
- リリース段階: In development
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=560700

Teams Rooms on Android の対面会議で Facilitator をワンタップで招待し、会議のメモ、意思決定、アクション項目を AI で記録できます。生成したメモは会議室の前面ディスプレイに表示されます。
