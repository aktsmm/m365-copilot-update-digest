## 全件

### 情報保護 - SharePoint および OneDrive の自動ラベル付けスケールの拡大

- 原題: Microsoft Purview: Information Protection - Auto-labeling scale increase for SharePoint and OneDrive
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/07/30
- リリース段階: In development
- 役割タグ: 管理者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=567890

SharePoint および OneDrive の自動ラベル付けの最大容量を、テナントあたり 1 日あたり 100,000 ファイルから最大 500,000 ファイルに増加します。これにより、組織はより多くの保存データをより迅速にラベル付けして保護し、既存のコンテンツ間のラベル付けのギャップを埋めることができます。機密ラベルと保護設定を適用すると...

### Copilot ダッシュボード - 対象ユーザー調査

- 原題: Microsoft Viva: Copilot Dashboard - Targeted Audience Surveys
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/07/30
- リリース段階: In development
- 役割タグ: 管理者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=568072

ターゲットを絞った対象者アンケートを使用すると、変革リーダーはすべてのライセンス ユーザーまたはアクティブ ユーザーに対して Copilot ダッシュボードから直接 Copilot Pulse アンケートを開始できます。オーディエンスは、Insights データを使用して自動的に更新され、組織や職務などの既存のダッシュボード フィルターを尊重し、人口レベルの調査を通じてプライバシーが保護されます。

### Microsoft Purview で外部 Web 検索向け DLP 保護を強化

- 原題: Microsoft Purview: Data Loss Prevention - Data Loss Prevention to safeguard sensitive information from external web search in Microsoft 365 Copilot and Copilot Chat
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/07/30
- リリース段階: In development
- 役割タグ: 管理者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=565870

機密データを含む Web 検索を保護するために、Microsoft Purview DLP for Microsoft 365 Copilot を拡張しています。このリアルタイム制御は、Microsoft 365 Copilot および Copilot Chat が外部の Web 検索に機密データを使用することを防ぎ、組織がデータ漏洩と過剰共有のリスクを軽減するのに役立ちます。

### 政府機関向けクラウドのプロンプトを保護するための Microsoft 365 Copilot のデータ損失防止

- 原題: Microsoft Purview: Data Loss Prevention for Microsoft 365 Copilot to safeguard prompts for government clouds
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/07/30
- リリース段階: Rolling out
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=561892

機密データを含むプロンプトを保護するために、Microsoft Purview DLP for Microsoft 365 Copilot を拡張しています。このリアルタイム制御は、プロンプトに機密データが含まれている場合やユーザーが要求した場合に Microsoft 365 Copilot と Copilot Chat が応答を返さないようにすることで、組織がデータ漏洩と過剰共有のリスクを軽減するのに役立ちます。
