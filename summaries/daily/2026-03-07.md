## 全件

### Windows で Copilot を使用して OneDrive ファイルの概要を共有する

- 原題: Microsoft Copilot (Microsoft 365): Use Copilot to Share with Summary for OneDrive files in Windows
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/03/07
- リリース段階: Launched
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=527840

Microsoft 365 Copilot の機能を Windows での日常のファイル エクスペリエンスに直接導入します。この機能を使用すると、ユーザーはファイルを要約し、その要約を共有ダイアログ内で送信できます。この機能は、ファイル エクスプローラーと OneDrive アクティビティ センターで利用できるようになります。

### OneDrive のフローティング Copilot ボタン

- 原題: Microsoft Copilot (Microsoft 365): Floating Copilot button in OneDrive
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/03/07
- リリース段階: Launched
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=513421

### 現在利用可能: Microsoft 365 Copilot での GPT-5.4 思考

- 原題: Available today: GPT-5.4 Thinking in Microsoft 365 Copilot
- ソース: Microsoft 365 Copilot Blog
- 公開日: 2026/03/07
- リリース段階: Rolling out
- 役割タグ: 作成者向け
- URL: https://techcommunity.microsoft.com/t5/microsoft-365-copilot-blog/available-today-gpt-5-4-thinking-in-microsoft-365-copilot/ba-p/4499746

本日、OpenAI の GPT-5.4 Thinking を Microsoft 365 Copilot および Microsoft Copilot Studio に導入します。これは、最近の GPT-5.3 Instant Update に加えて利用可能です。 GPT‑5.4 思考を使用すると、Copilot は推論、コーディング、エージェントの進歩を組み合わせることにより、複雑な作業についてより深く考えることができます。
