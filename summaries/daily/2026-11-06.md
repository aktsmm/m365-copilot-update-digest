## 全件

### [教育] Teach を使用して複数週間の単位計画を作成する

- 原題: Microsoft Copilot (Microsoft 365): [Education] Create multi-week unit plans with Teach
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/11/06
- リリース段階: Launched
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=577392

教育者は Microsoft 365 Copilot の Teach を使用して、複数のレッスンまたは週にわたる構造化された単元計画を作成できます。計画コンポーネントをカスタマイズして、単元全体で関連する授業計画やクイズを整理できます。 ＃教育

### Microsoft Copilot Studio: エージェント ワークフローで MCP 準拠のツールを使用する

- 原題: Microsoft Copilot Studio: Use MCP-compliant tools in agent workflows
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/11/06
- リリース段階: Launched
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=562221

MCP サポートにより、独自のシステム、動的なナレッジ ソース、カスタム アクションをエージェント ワークフローに統合し、ワークフローの信頼性を維持しながら拡張性を加速します。この統合により、エージェントやワークフロー全体での再利用が向上し、統合の重複が削減され、新たなオープン アンド ソリューションが受け入れられます。

- ソース: Microsoft 365 Roadmap
- 公開日: 2026/11/06
- リリース段階: Retirement
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=502546

1. メーカーは、特定のコンテナーのカスタム コネクタ データに基づいて作成されたエージェント内のデータをスコープできるようになりました。 2. これらのコンテナは、カスタム コネクタの作成/更新中に定義されます。

### Microsoft 365 Copilot (Microsoft 365): 会計スキル

- 原題: Microsoft 365 Copilot (Microsoft 365): Accounting skills
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/11/06
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
