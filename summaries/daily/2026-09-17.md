### Microsoft 365 アプリ: M365 Copilot アプリの検索のクイック アクセス セクションから Copilot ノートブックへの参照を追加します

- 原題: Microsoft 365 app: Add references to your Copilot Notebooks from the Quick Access section in Search on the M365 Copilot app
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/09/17
- リリース段階: Launched
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=510099

ユーザーは、M365 Copilot アプリの検索のクイック アクセス セクションを通じて、Copilot ノートブックへの参照をすばやく追加できます。

### Copilot ノートブックで Power BI レポートを参照可能に

- 原題: Microsoft Copilot (Microsoft 365): Power BI reports as references in Copilot Notebooks
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/09/17
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=569928

Copilot ノートブックで Power BI レポートを参照として追加できるようになります。レポート データをファイルと共に取り込み、組織データに基づくより関連性の高い要約、プレゼンテーション、ブリーフの生成に活用できます。

### SharePoint ドキュメント ライブラリまたはフォルダーを対象としたクエリのメタデータ理解のサポート

- 原題: Microsoft Copilot (Microsoft 365): Metadata understanding support for queries scoped to SharePoint document libraries or folders
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/09/17
- リリース段階: Launched
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=516044

SharePoint ライブラリまたはフォルダーがアタッチされているか、その URL が提供されている場合、Microsoft 365 Copilot のクエリに対する列メタデータのサポートが導入されています。この機能強化により、Copilot が選択したライブラリから追加のメタデータを活用できるようになり、より正確で意味のある結果が得られるため、コンテキストの関連性が向上します。

### Copilot での詳細な引用

- 原題: Microsoft Copilot (Microsoft 365): Deep citations in Copilot
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/09/17
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=523223

深い引用により、ユーザーは参照の関連部分に直接リンクすることで Copilot の結果を迅速に検証でき、信頼性が高まります。 Word と PPT ファイルから始めて、会議、Web、PDF の参照を追加します。

### モバイルの検索から Copilot に質問する

- 原題: Microsoft Teams: Ask Copilot from Search on Mobile
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/09/17
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=571299

検索を終了せずに答えを得ることができます。 Teams の検索バーに入力すると、検索結果の横に Copilot に問い合わせるオプションが表示されます。検索結果ページから [Ask Copilot] を選択して、クエリを Copilot の会話に変換することもできます。これにより、情報をすばやく検索し、回答を得て、フォローアップの質問をすることができます。
