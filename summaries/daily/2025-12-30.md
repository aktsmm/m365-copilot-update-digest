### Microsoft 365 Copilot の更新

- 原題: Microsoft Copilot (Microsoft 365): [Copilot Extensibility] [1.02] Generate Word, Excel, and PowerPoint documents from agents built in Microsoft 365 Copilot
- ソース: Microsoft 365 Roadmap
- 公開日: 2025/12/30
- リリース段階: Launched
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=506753

Microsoft 365 Copilot 内の Agent Builder を使用すると、ユーザーはエージェントとチャットすることで PowerPoint デッキ、Excel スプレッドシート、Word ドキュメントの生成などの Office スキルを使用できるようになります。これはユーザーの利便性を高めるのに役立ちます。
