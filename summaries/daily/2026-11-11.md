### Work IQ: Work IQ MCP でビジネス プロセスを管理するためのビジネス スキル

- 原題: Work IQ: Business Skills to manage your business processes in Work IQ MCP
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/11/11
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=573290

ビジネス スキルは、組織がどのように仕事を遂行するかを表す自然言語の指示です。これらは、エージェントが理解して従うことができる形式で、ビジネス プロセス、ポリシー、およびドメインの知識を表します。各スキルは、特定の種類の作業を完了する方法、つまり必要な手順、情報などを説明します。

### OneNote の Copilot Chat はコンテンツを作成、編集、調整できます

- 原題: Microsoft Copilot (Microsoft 365): Copilot Chat in OneNote can create, edit, and refine content
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/11/11
- リリース段階: In development
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=573446

OneNote の Copilot は、新しいコンテンツを生成し、編集モードで直接編集できます。このモードでは、ページ、セクション、またはノートブックを作成、名前変更、削除できるだけでなく、ページ内のコンテンツを追加または編集することもできます。 Copilot は、WorkIQ 全体からコンテンツを取り込むだけでなく、作成などの他のワークフロー全体のアクションを完了することもできます。

### Microsoft 365 Copilot のフェデレーション Copilot コネクタ

- 原題: Microsoft Copilot (Microsoft 365): Federated Copilot Connectors in Microsoft 365 Copilot

- 公開日: 2026/11/11
- リリース段階: In development
- 役割タグ: 作成者向け

Federated Copilot コネクタを使用すると、ユーザーは Microsoft Copilot をお気に入りのサードパーティ ソースに安全に接続し、Model Context Protocol (MCP) を使用してリアルタイムでデータを取得できます。 Federated Copilot コネクタは、Microsoft に顧客データを保存したりインデックスを作成したりしません。アクセスはユーザー自身の ID を使用してリアルタイムで行われます。

### Microsoft Copilot (Microsoft 365): Copilot People Connectors は、差別化されたアクセス制御による個人データの取り込みを導入します。

- 原題: Microsoft Copilot (Microsoft 365): Copilot People Connectors introduces people data ingestions with differentiated access control
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/11/11
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け

Copilot People Connector は、アクセス制御付きの個人データの Microsoft 365 へのインポートをサポートするようになりました。このリリースにより、組織は関連するアクセス制御リスト (ACL) とともに外部システムから個人データを Microsoft 365 に取り込むことができるようになり、Copilot がソース システムで定義された既存のアクセス許可を確実に尊重できるようになります。
