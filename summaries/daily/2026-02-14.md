## 全件

### デスクトップ アプリ用 Excel のエージェント モード

- 原題: Microsoft Copilot (Microsoft 365): Agent Mode in Excel for desktop apps
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/02/14
- リリース段階: Launched
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=542182

エージェント モードが Windows および Mac 上の Excel の Copilot にリリースされ、ユーザーはマルチステップ ワークフローを使用して Copilot でワークブックを構築および編集できるようになります。対象となるライセンスは、Open AI モデルと Anthropic モデルの両方を含む、使用するモデルを選択できるようになりました。

### Excel のエージェント モード

- 原題: Microsoft Copilot (Microsoft 365): Agent Mode in Excel
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/02/14
- リリース段階: Launched
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=527835

エージェント モードでは、Copilot と並行してワークブックを構築および編集できます。予算の更新、財務モデルの作成、またはデータの分析を行う場合、エージェント モードは、表、グラフ、ピボットテーブル、数式などの Excel の最も強力なツールを使用して、作業を完了するのに役立ちます。

### Copilot によるスケジュール設定

- 原題: Microsoft Copilot (Microsoft 365): Scheduling with Copilot
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/02/14
- リリース段階: Launched
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=532735

Copilot を使用したスケジュール: ユーザーはチャットから直接会議をスケジュールできるようになりました。 Copilot に同僚との会議のスケジュールを設定するよう依頼するだけで、利用可能な時間を検索し、部屋を予約し、議題を草案し、招待状を送信するなど、すべてチャット エクスペリエンス内で実行されます。この機能は段階的に展開され、一般的には...

### Microsoft 365 管理センター: Copilot - 請求と使用量: 使用量が多いユーザー

- 原題: Microsoft 365 admin center: Copilot - Billing & usage: High-usage users
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/02/14
- リリース段階: In development
- 役割タグ: 管理者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=557176

Copilot の従量課金制使用量が多い (つまり、2000 クレジットを超える) ユーザーのリストを表示します。このページで直接 Copilot ライセンスを購入し、使用頻度の高いユーザーに割り当てることができます。

### アドレス バーから Copilot に問い合わせる

- 原題: Microsoft Edge: Ask Copilot from the address bar
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/02/14
- リリース段階: Launched
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=493287

ユーザーが Edge アドレス バーに検索クエリを入力すると、検索クエリを Copilot に直接送信して、Web 全体 (およびプレミアム ユーザーの場合は作業コンテンツ) から取得した、より的を絞った合成された回答を得ることができます。
