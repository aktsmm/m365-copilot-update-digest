## 全件

### Microsoft 365 Copilot の更新

- 原題: Microsoft Copilot (Microsoft 365): [Copilot Extensibility] Admins can deploy and govern agents with MCP in the M365 admin center
- ソース: Microsoft 365 Roadmap
- 公開日: 2025/09/20
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=501124

管理者は、企業で安全に使用できるように、M365 管理センターでモデル コンテキスト プロトコル (MCP) で構築されたエージェントを展開、監視、管理できます。

### Copilot で生成した PowerPoint プレゼンテーションのアウトラインをチャットのページ経由で編集します

- 原題: Microsoft Copilot (Microsoft 365): Edit your Copilot-generated PowerPoint presentation outline via Pages in Chat
- ソース: Microsoft 365 Roadmap
- 公開日: 2025/09/20
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=501785

PowerPoint デッキを作成する前に、ページ内で Copilot によって生成されたプレゼンテーション アウトラインを編集して共同作業できるようになりました。
