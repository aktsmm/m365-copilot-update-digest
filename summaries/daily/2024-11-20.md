## 全件

### Word ファイルからプレゼンテーションを作成する

- 原題: OneDrive: Create a presentation from a Word file
- ソース: Microsoft 365 Roadmap
- 公開日: 2024/11/20
- リリース段階: In development
- 役割タグ: 管理者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=469501

Copilot を使用すると、Word ファイルを使用して、ワンクリックでプレゼンテーションの最初の草稿を作成できます。この機能には Microsoft Copilot for Microsoft 365 ライセンスが必要であり、次の目的で使用できます。

### Copilot の応答を Word ファイルに変換する

- 原題: OneDrive: Convert Copilot response into a Word file
- ソース: Microsoft 365 Roadmap
- 公開日: 2024/11/20
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=469502

Copilot が生成した概要や FAQ が気に入りましたか?ワンクリックで、Copilot の回答を Word 文書に変換できるようになりました。この機能には Microsoft Copilot for Microsoft 365 ライセンスが必要です...
