## 全件

### チャット: モデル セレクターを介した UBB モデルへのアクセス

- 原題: Microsoft Copilot (Microsoft 365): Chat: Access to UBB models via the model selector
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/10/03
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=571400

ユーザーは、チャットのモデル セレクターから従量制課金 (UBB) が必要なモデルにアクセスできるようになります。テナント管理者は、ユーザーがこれらのモデルを操作できるようにクレジットを割り当てる必要があります。ユーザーが割り当てられたクレジットを消費すると、テナント管理者にクレジットを要求できるようになります。

### Commercial Journey - Microsoft 365 Copilot ユーザー向けの AI を活用したタスク完了

- 原題: Microsoft Edge: Commercial Journeys - AI-powered task completion for Microsoft 365 Copilot users
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/10/03
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=561040

Commercial Journeys は、インフォメーション ワーカーが Microsoft Edge で閲覧する際に最も重要な作業を常に把握できるように支援します。 AI を活用して、Copilot の新しいタブ ページに未完了のタスク、新しいタスク、繰り返し発生するタスクをプロアクティブに表示します。各タスクがなぜ今重要なのかを説明するコンテキスト豊富なカードが表示されます。ワンクリックでガイド付きの画面が開きます...

### 営業エージェントで Dataverse ビジネス スキルを使用する

- 原題: Microsoft Copilot (Microsoft 365): Use Dataverse Business Skills in Sales Agent
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/10/03
- リリース段階: In development
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=571394

ビジネス スキルは、Dataverse に作成および保存されている自然言語の指示であり、営業エージェントに特定の組織内で仕事がどのように行われるかを教えるものです。ビジネス スキルを使用すると、組織は、ビジネス プロセスを表す、営業担当者が従うべき自然言語の指示を作成できます。
