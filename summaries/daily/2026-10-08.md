## 全件

### Excel の Copilot の計画モード

- 原題: Excel: Plan Mode for Copilot in Excel
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/10/08
- リリース段階: Launched
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=560338

Excel の Copilot の計画モードを使用すると、ブック内の内容が更新される前に明確な段階的なアプローチの概要が示されるため、ユーザーは自信を持って複雑な変更を行うことができます。ユーザーは、Copilot がどのようにタスクを完了する予定であるかを確認し、どのデータまたは機能が使用されるかを確認し、必要に応じて計画を調整して、編集内容が適切であることを確認できます。

- リリース段階: Launched

### Workforce Insights エージェント

- 原題: Microsoft Copilot (Microsoft 365): Workforce Insights Agent
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/10/08
- リリース段階: In development
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=515145

Microsoft 365 Copilot の Workforce Insights (WFI) エージェントは、複雑な従業員データを明確で実用的な洞察に変換することで、リーダー、マネージャー、およびその代表者が組織を迅速に理解できるように設計されたエージェントです。 WFI エージェントを使用すると、リーダーは組織の構造やチームをすばやく調査できます...

### Copilot Analytics - Agent 365 ダッシュボードのエージェント価値に関する洞察

- 原題: Microsoft Viva: Copilot Analytics - Agent value insights in Agent 365 Dashboard
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/10/08
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=570847

お客様は、Microsoft Viva Insights (Copilot Analytics) の Agent 365 ダッシュボードで価値に関する洞察を表示できるようになりました。これらの洞察は、ビジネス リーダーや変更および導入のスペシャリストが、エージェントが使用されているかどうかだけでなく、エージェントが提供する推定支援時間や作業の種類についても理解するのに役立ちます。
