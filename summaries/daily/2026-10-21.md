### OneDrive iOS の Copilot コンテキスト メニューを使用して PDF をレビューする

- 原題: Microsoft Copilot (Microsoft 365): Review PDFs using the Copilot context menu on OneDrive iOS
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/10/21
- リリース段階: Retirement
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=568790

Microsoft 365 Copilot を使用すると、モバイル上で PDF レビューを迅速かつ簡単に行うことができます。 OneDrive iOS の PDF 内のテキストを選択し、[Ask Copilot] をタップすると、選択内容について説明、要約、翻訳、またはカスタムの質問をすることができます。これと同じコンテキスト内での Copilot エクスペリエンスがデスクトップですでに一般提供されており、今度は OneDrive iOS でも提供されます。

### 増分クロールでサポート許可の同期が失われる

- 原題: Microsoft Copilot (Microsoft 365): Support permission sync missed in incremental crawl
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/10/21
- リリース段階: Launched
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=503570

以前は、アクセス許可は定期的なフル クロールでのみ同期されていました。通常、ほとんどのコネクタでは、デフォルトの頻度が 1 日でした。現在、増分的な方法でより頻繁に権限の同期を実行できるようになりました。

### Copilot の法的なプラグイン

- 原題: Word: Legal plugins in Copilot
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/10/21
- リリース段階: Rolling out
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=571884

Copilot の法務プラグインは、法律専門家が法的文書を要約、草案、レビュー、修正するのに役立つ専用のスキルを提供します。 Word および Cowork で利用できるこれらのプラグインは、Microsoft 365 の作業コンテキストを使用し、サポートされているサードパーティの法的ソースに接続できます。

### Copilot Analytics - エージェント ダッシュボードからのメトリクスのエクスポート

- 原題: Microsoft Viva: Copilot Analytics - Export metrics from Agent Dashboard
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/10/21
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=560538

ユーザーは、匿名化された行レベルのエージェントのメトリクスと属性をエージェント ダッシュボードからエクスポートできます。エクスポートされたデータは、個人識別情報が削除された状態で、組織全体にわたるエージェントの使用状況とユーザーレベルのエージェントのやり取りに関する詳細な洞察を提供します。 #copilotcontrolsystem
