### データ損失防止 - 機密ラベルが付いているコンテンツに対する Microsoft 365 Copilot の処理を制限するデータ損失防止

- 原題: Microsoft Purview: Data Loss Prevention - Data Loss Prevention to restrict Microsoft 365 Copilot processing on content with sensitivity labels
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/01/22
- リリース段階: Launched
- 役割タグ: 管理者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=520772

Microsoft Purview Data Loss Prevention は Microsoft 365 Copilot に拡張されています。この機能により、DLP ポリシーで企業のグラウンディング データの機密ラベルを検出し、制限を行うことができるようになります。

### Confluence Copilot コネクタのクエリ フィルターの調整のサポート

- 原題: Microsoft Copilot (Microsoft 365): Support for refining query filters for Confluence Copilot connectors
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/01/22
- リリース段階: In development
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=503571

この機能は、Confluence Cloud コネクタと Confluence オンプレミス コネクタの両方にわたるクエリ フィルタリングを強化および標準化します。 Confluence Cloud コネクタでは、フィルタリングするための簡素化されたオプションが導入されています。
