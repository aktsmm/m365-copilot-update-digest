## 全件

### Microsoft 365 アプリ: Microsoft 365 Copilot アプリの新しい Copilot ノートブック デザイン (Android)

- 原題: Microsoft 365 app: New Copilot Notebooks design in the Microsoft 365 Copilot App (Android)
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/07/10
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=566704

Microsoft 365 Copilot アプリ (Android) の Copilot ノートブックを使用すると、ユーザーは関連するチャット、出力作成、参照を永続的な AI ワークスペースに整理できるようになりました。 Copilot は Notebook に蓄積されたコンテキストを使用して応答をグラウンディングするため、作業は毎回最初からやり直すのではなく、セッションをまたいで継続されます。

### Copilot Analytics - Cowork と WorkIQ の支出と使用状況に関する洞察

- 原題: Microsoft Viva: Copilot Analytics - Insights in Cowork and WorkIQ spend and usage
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/07/10
- リリース段階: Rolling out
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=566302

グループまたはチーム レベルでの AI 支出 (Copilot クレジットの使用量) に関する洞察は、ダッシュボードとしての Viva Insights および Advanced Insights で利用できるようになります。このリリースの対象となるサービスは、Cowork および Work IQ API です。ダッシュボード エクスペリエンスは、少なくとも 5 人の直属の部下 (範囲限定アクセス) を持つマネージャーが利用できます。

- リリース段階: Rolling out

### Insider Risk Management - Defender で利用可能な IRM 用 DS Triage Agent

- 原題: Microsoft Purview: Insider Risk Management - DS Triage Agent for IRM available in Defender
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/07/10
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=567472

Microsoft Defender 内で Insider Risk Management (IRM) アラート エージェントの概要のサポートを導入し、調査員が Defender アラート キュー内の主要なトリアージの洞察に直接アクセスできるようにします。 IRM Triage Agent がアクティブな場合、Microsoft Defender に表示される IRM アラートには、エージェントの概要が含まれるようになります。
