## 全件

### Copilot Studio で作成者間のエージェント共有に対応

- 原題: Microsoft Copilot Studio: Agent Sharing amongst makers
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/10/29
- リリース段階: Launched
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=569475

Copilot Studio の新しい GHCP ハーネスで、作成者間でエージェントを共有できるようになります。自動割り当てのセキュリティ ロールにより、他の作成者へ閲覧者または編集者としてアクセスを付与できます。

### Microsoft 365 Copilot の会議・チャット機能を更新

- 原題: Microsoft 365 Admin Center: Usage reports - Message consumption for Pay-as-you-go experiences in Copilot Chat.
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/10/29
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=490738

IT 管理者が Copilot Chat に対して従量課金制が有効になっている請求メッセージのコストを管理するのに役立つ新しいレポート。レポートには、ユーザーごと、請求ポリシーごと、エージェント レベルおよびエージェントとユーザー レベルのペアごとの請求メッセージのドリルダウンが含まれます。 #copilotcontrolsystem

### Copilot Studio: GitHub での Web ブラウジングにコンピュータを使用する Copilot Harness

- 原題: Copilot Studio: Computer Use for web browsing on Microsoft Copilot Harness
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/10/29
- リリース段階: In development
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=576272

Microsoft Copilot Studio エージェントが、GitHub Copilot Harness を活用したネイティブ機能として Web サイトを参照し、操作できるようにします。自然言語の指示を使用して、エージェントは Web ページを移動し、情報を抽出し、ファイルをダウンロードできます。その後、エージェントはその情報やファイルを他のファイルと一緒に使用できるようになります。

### 画像について Copilot に質問する

- 原題: Microsoft Edge: Ask Copilot about an image
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/10/29
- リリース段階: In development
- 役割タグ: 管理者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=566864

Edge の画像について Copilot に質問すると、ユーザーは Edge コンテキスト メニューから直接 Copilot に画像を送信することで、Web からの画像を即座に分析できるようになり、ブラウジング エクスペリエンスを離れることなく、簡単に質問したり、洞察を得たり、ビジュアル コンテンツを理解したりすることができます。管理者は、この機能の可用性を制御できます...

### Dynamics 365 Contact Center: ユーザー グループとのブルズアイ ルーティングを使用して会話を調整します

- 原題: Dynamics 365 Contact Center: Use bullseye routing with user groups to orchestrate conversations
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/10/29
- リリース段階: Rolling out
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=576606

ユーザー グループを使用したブルズアイ ルーティングにより、会話の待ち時間が増加するにつれて、適格な代表者のプールを自動的に拡大する段階的な割り当て戦略が可能になります。このアプローチでは、固定プールから割り当てたり、オーバーフロー ルールがトリガーされるのを待ったりするのではなく、同心円状の可用性が段階的に拡大されます。
