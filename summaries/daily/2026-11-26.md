## 全件

### Edge の選択テキスト向け Copilot 要約・翻訳・引用機能の提供を中止

- 原題: Microsoft Edge: Summarization, Translation, and Citation will soon be supported by Microsoft Copilot and Microsoft 365 Copilot Chat in our menus
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/11/26
- リリース段階: Retirement
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=497135

ブラウザーで選択したコンテンツから開く Edge のメニューで、Microsoft Copilot と Microsoft 365 Copilot Chat による要約、翻訳、引用を利用できる予定でした。なお、この提供計画は中止されました。

### Word の Copilot Chat Agent mode で文書を作成・編集・改良

- 原題: Microsoft Copilot (Microsoft 365): [Copilot Chat] Agent mode in Word enables conversational support to create, edit and refine document content from chat
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/11/26
- リリース段階: Launched
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=543241

Microsoft 365 Copilot ライセンスのないユーザーも利用できます。チャットの編集モードで自然言語を使い、新規・既存の Word 文書を作成、編集、改良できます。必要に応じて Copilot が確認質問を行い、編集後に実施内容と推奨する次の手順をまとめます。

### Copilot はデフォルトで Word でドキュメントを編集できます

- 原題: Microsoft Copilot (Microsoft 365): Copilot can edit your document by default in Word
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/11/26
- リリース段階: Launched
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=557673

Word での Copilot とのデフォルトのチャット エクスペリエンスでは、Copilot がドキュメントを直接編集できるようになりました。 Copilot によって行われたすべての変更は完全にレビュー可能で元に戻すことができ、ユーザーは必要に応じてこのエクスペリエンスをオフにすることができます。

### Researcher の Copilot メモリ

- 原題: Microsoft Copilot (Microsoft 365): Copilot memory in Researcher
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/11/26
- リリース段階: Retirement
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=562996

Researcher 内の Copilot メモリは、過去のやり取りから関連するコンテキストを引き出し、複雑なトピックの調査時に洞察の根拠付け、出力のパーソナライズ、繰り返し設定の削減に役立ちます。ただし、このロードマップ項目は現状に即していないとして、ロードマップから削除される予定です。
