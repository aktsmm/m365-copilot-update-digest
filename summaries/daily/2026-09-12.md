### Copilot Chat は、スキャンされた PDF からの検索結果とより適切に一致できるようになりました。

- 原題: Microsoft Copilot (Microsoft 365): Copilot Chat can now better match search results from Scanned PDFs
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/09/12
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=559613

Copilot Chat は、スキャンされた PDF の検索結果と、Copilot ユーザーが作業中のファイル (以前は検索して見つけるのが困難だったコンテンツ) の検索結果をより正確に照合できるようになりました。この機能は、新規/更新されたユーザーの作業ファイルに対して今後も機能します。

### Excel で Copilot を使用して編集 (Web、Win32、Mac) - GCC

- 原題: Microsoft Copilot (Microsoft 365): Edit with Copilot in Excel (Web, Win32, Mac) - GCC
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/09/12
- リリース段階: In development
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=542181

Edit with Copilot では、Copilot と並行してワークブックを構築および編集できます。予算の更新、財務モデルの作成、またはデータの分析を行う場合、Copilot は表、グラフ、ピボットテーブル、数式などの Excel の最も強力なツールを使用して、作業を完了するのに役立ちます。

### エンドポイント データ損失防止 - カスタム ポリシーを通じて、スナップショットのリコールに対する保護を Copilot + PC デバイスに拡張します

- 原題: Microsoft Purview: Endpoint Data Loss Prevention - Expand protection to Copilot + PC devices for Recall snapshots through custom policies
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/09/12
- リリース段階: Rolling out
- 役割タグ: 管理者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=560396

Microsoft Purview Endpoint データ損失防止は、最初にリコール スナップショットをサポートし、制限された機密ラベルと機密情報の種類 (SIT) を含むウィンドウのキャプチャを防止するポリシーが存在するかどうかを判断するために、対象範囲を Copilot + PC に拡大しています。 Purview 管理者は、Endpoint DLP カスタムを作成します。
