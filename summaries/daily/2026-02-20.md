## 全件

### v.145 - AI 生成アプリケーションを安全に有効にする

- 原題: Microsoft Edge: v.145 - Securely enable AI generated applications
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/02/20
- リリース段階: Launched
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=525366

最新の AI の進歩を活用して、データを気にすることなく、Edge のお気に入りのツールを使用してプロトタイプ、学習アプリケーション、または対話型レポートを構築します。この拡張機能により、アプリは AI で生成されたコードを安全に実行するためにいくつかの新しいセキュリティ強化を利用できるようになります。

### Word エージェント

- 原題: Microsoft Copilot (Microsoft 365): Word Agent
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/02/20
- リリース段階: Rolling out
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=543420

Word Agent は、リサーチ、構造、書式設定の処理に役立ち、アイデアに集中し続けることができます。マルチターン チャットを使用して下書きを修正したり、Word で開いて完全な編集や共同作業を行ったりできます。戦略計画、政策文書、技術文書など、長文で情報量の多い作業向けに設計されています。

### Excel でのエージェント モードのローカル ファイル サポート

- 原題: Microsoft Copilot (Microsoft 365): Local file support for Agent Mode in Excel
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/02/20
- リリース段階: In development
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=557564

デバイスに保存されている最新の Excel ワークブックのサポートが Excel のエージェント モードに拡張され、ファイルがローカルに保存されているかクラウドに保存されているかに関係なく、ユーザーは Excel の Copilot でマルチステップ編集機能を柔軟に使用できるようになります。
