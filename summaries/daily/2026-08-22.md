## 全件

### Work IQ API – エージェントとワークフロー用の統合 REST エンドポイント

- 原題: Microsoft Copilot (Microsoft 365): Work IQ APIs – Unified REST Endpoint for Agents and Workflows
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/22
- リリース段階: Launched
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=559021

Work IQ の新しい REST エンドポイントを導入します。これは、エージェントとワークフローを呼び出すための統合されたエントリ ポイントとして機能し、従来の Copilot Chat エンドポイントに代わる一貫したスケーラブルな代替手段を提供します。

### 管理センターに GCC High・DoD 向け M365 Copilot 使用状況レポートを追加

- 原題: Microsoft Copilot (Microsoft 365): Microsoft 365 admin center – New Microsoft 365 Copilot usage report for GCC High & DoD
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/22
- リリース段階: Launched
- 役割タグ: 管理者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=567120

Microsoft 365 Copilot をカバーする新しい使用状況レポートを導入します。このレポートには、有効なアクティブ ユーザーの合計、Microsoft 365 アプリごとのブレイクアウトを伴う Copilot の使用状況、およびユーザー レベルのアクティビティの分析情報 (既定では匿名化されます) が含まれます。 #copilotcontrolsystem

### PowerPoint の Copilot 編集で Work IQ からメールを参照可能に

- 原題: Microsoft Copilot (Microsoft 365): Reference an email with Work IQ when using Edit with Copilot in PowerPoint to create a presentation
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/22
- リリース段階: Launched
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=555888

PowerPoint で Edit with Copilot を使用してプレゼンテーションを作成するときに、Work IQ で電子メールを参照できるようになりました。

### データ ライフサイクル管理 – Copilot メモリの保持

- 原題: Microsoft Purview: Data Lifecycle Management – Retention for Copilot Memory
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/22
- リリース段階: In development
- 役割タグ: 管理者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=569612

Microsoft 365 Copilot メモリの保持期間を構成して、セキュリティ、コンプライアンス、および調査シナリオに備えてメモリ項目の履歴バージョンを保存できるようにします。Copilot のメモリには、保存されたメモリとチャット履歴から推測される詳細が含まれており、よりパーソナライズされたコンテキスト認識型の Copilot エクスペリエンスが可能になります。Copilot の私...
