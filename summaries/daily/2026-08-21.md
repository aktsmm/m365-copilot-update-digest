## 全件

### Microsoft Purview で外部 Web 検索向け DLP 保護を強化

- 原題: Microsoft Purview: Data Loss Prevention - Data Loss Prevention to safeguard sensitive information from external web search in Microsoft 365 Copilot and Copilot Chat
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/21
- リリース段階: Launched
- 役割タグ: 管理者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=565870

機密データを含む Web 検索を保護するために、Microsoft Purview DLP for Microsoft 365 Copilot を拡張しています。このリアルタイム制御は、Microsoft 365 Copilot および Copilot Chat が外部の Web 検索に機密データを使用することを防ぎ、組織がデータ漏洩と過剰共有のリスクを軽減するのに役立ちます。

### Microsoft 365: OneDrive 用の従量課金制ストレージ

- 原題: Microsoft 365: Pay-as-you-go storage for OneDrive
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/21
- リリース段階: In development
- 役割タグ: 管理者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=562352

追加の OneDrive ストレージ用の新しい従量課金制の消費量ベースのメーター。どの OneDrive アカウントがライセンスされたストレージ制限を超えて拡張できるかを制御し、選択したユーザーに必要に応じて追加のスペースを提供します。

### セルフサービス同期コネクタ

- 原題: Microsoft Copilot (Microsoft 365): Self-serve sync connectors
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/21
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=568788

セルフサービス同期コネクタを使用すると、ユーザーは Jira や Confluence Cloud などの独自の外部データ ソースを Microsoft 365 Copilot に安全に接続できます。ユーザーは、自分の資格情報と権限を使用して、既にアクセス権を持っているコンテンツを同期し、Copilot Chat や Microsoft Search で検索できるようにすることができます。

- リリース段階: In development

リモート会議の参加者は、室内に誰がいるのかを把握し、室内の参加者を識別し、インテリジェント カメラやクラウド上の音声と顔のプロファイルを使用してホバーオーバー連絡先カードを提供する新しい IntelliFrame 人物ラベルを使用して会話をより適切に追跡できます。 ... のライセンスが付与された Windows 上の Teams Rooms で利用できます。

### Android 上の Teams Rooms での通訳エージェントのサポート

- リリース段階: Rolling out
