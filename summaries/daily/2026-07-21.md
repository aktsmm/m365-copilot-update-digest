### Teams イベントの空室状況シグナル

### GCC High および DoD で利用可能なアクションを備えた宣言型エージェント

- 原題: Microsoft Copilot (Microsoft 365): Declarative agents with Actions available in GCC High and DoD
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/07/21
- リリース段階: Launched
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=564606

アクションを備えた宣言型エージェントを使用すると、Microsoft 365 Copilot は、チャット エクスペリエンス内で API、プラグイン、エンタープライズ ワークフローを直接呼び出すことにより、実際のアクションを実行できるようになります。カスタム アクションを使用すると、宣言型エージェントは外部システムの呼び出し、操作の実行、データの取得または更新を行うことができ、Q&A を超えて完全な機能を実現できます。

### Microsoft 365 Copilot および Copilot Chat での外部電子メールの処理を制限するデータ損失防止

- 原題: Microsoft Purview: Data Loss Prevention to restrict processing external emails in Microsoft 365 Copilot and Copilot Chat
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/07/21
- リリース段階: In development
- 役割タグ: 管理者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=561552

外部電子メールからのリスクを保護するために、Microsoft 365 Copilot および Copilot Chat 用の Microsoft Purview DLP を拡張しています。このリアルタイム制御は、Microsoft 365 Copilot と Chat が組織外部の送信者からの電子メールを処理しないようにすることで、組織のデータ リスクを軽減するのに役立ちます。
