### Work IQ API: 従量課金制の使用法

- 原題: Microsoft Copilot (Microsoft 365): Work IQ APIs: Pay‑As‑You‑Go usage
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/09/22
- リリース段階: Launched
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=559017

Work IQ エンドポイントへの従量課金制アクセスを有効にし、開発者が事前に割り当てられたライセンスを必要とせずにエージェントと機能を呼び出すことができ、リクエストごとに呼び出されたエージェントとモデルに基づいて使用量が請求されます。

### AI を使用してページ上にグラフを作成する

- 原題: SharePoint: Create charts on pages with AI
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/09/22
- リリース段階: Launched
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=560076

この機能により、作成者は SharePoint ページを編集するときに、SharePoint の AI を使用してリッチでインタラクティブなグラフを作成できるようになります。作成者は、SharePoint ページ上のチャット内で、作成したいグラフをわかりやすい言葉で説明できます。

### Microsoft 365 管理センター: Microsoft 365 Copilot Search のための権威コンテンツ管理

- 原題: Microsoft 365 Admin Center: Authoritative content management for Microsoft 365 Copilot Search
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/09/22
- リリース段階: Launched
- 役割タグ: 管理者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=503553

信頼できるコンテンツとみなされる SharePoint サイトを指定して管理し、Microsoft 365 Copilot Search での関連性とランキングを強化します。 Microsoft 365 管理センターの [Copilot] > [検索] > [権限のあるコンテンツ] で、最大 100 の SharePoint サイトを追加して管理します。 #copilotcontrolsystem

### Teams で AI 生成の会議アーカイブに対応

- 原題: Microsoft Teams: AI-generated meeting archive for knowledge retention
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/09/22
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=558933

管理者は、Copilot (およびファシリテーター) がトランスクリプトの保存期間を超えて会議からの重要な洞察を保持できるようにするテナント全体のポリシーを有効にすることができます。これにより、Copilot はトランスクリプトの有効期限が切れた後でも、過去の会議に関する質問に回答し続けることができます。管理者は、この AI によって生成された会議の継続時間を設定することもできます。

- 役割タグ: 管理者向け / 作成者向け
