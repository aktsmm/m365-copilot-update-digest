## 全件

### Microsoft Teams への高速音声登録

- 原題: Microsoft Teams: Express voice enrollment in Microsoft Teams
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/11/14
- リリース段階: Launched
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=537269

高速音声登録により、Teams に音声を迅速かつ簡単に登録できます。プロファイルにより、音声分離、話者認識、会議室での識別やトランスクリプト、Microsoft 365 Copilot からの強化された会議の要約や分析情報などの機能が有効になります。音声プロファイルをまだお持ちでない場合は、次の手順に従ってください...

### ファシリテーターが質問を検出して回答します

- 原題: Microsoft Teams: Facilitator detects and answers questions
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/11/14
- リリース段階: In development
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=558341

ファシリテーターは、Teams 会議中に出された未解決の質問を自動的に検出し、Web 検索を使用して回答を提供するようになりました。参加者が質問 (例: 「LLM とは何ですか?」) をしても誰も答えない場合、ファシリテーターは答えを見つけるためのプロンプトを投稿します。参加者は「はい」を選択して、エージェントに質問への回答を探してもらうことができます。

### Microsoft 365 Copilot Search で SharePoint Online のカスタム プロパティ検索に対応

- 原題: Microsoft Copilot (Microsoft 365): Microsoft 365 Copilot Search Supports SharePoint Online Custom Properties Search
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/11/14
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=508526

SharePoint Online の会社のカスタム プロファイル プロパティに基づいて、Microsoft 365 Copilot Search を通じてユーザーを発見および検索します。

### 営業エージェントで推奨されるリードと商談のアクションを検出し、それに基づいて行動します。

- 原題: Microsoft Copilot (Microsoft 365): Discover and act on recommended lead and opportunity actions in Sales agent
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/11/14
- リリース段階: In development
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=579977

販売者は、販売エージェントですでに優先順位が設定されている見込み顧客と商談の推奨事項を見つけて、それに基づいて行動できます。単一の優先順位付きリストにより、販売者は各エージェントを個別に監視したり、アクション自体に優先順位を付けたりすることなく、注意が必要なものを確認することができます。販売者は、推奨される各アクションを確認できます。
