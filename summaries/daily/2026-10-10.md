## 全件

### Copilot Studio で共有プラグインを検出して使用する

- 原題: Microsoft Copilot Studio: Discover and use shared plugins in Copilot Studio
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/10/10
- リリース段階: In development
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=570669

Copilot Studio は Microsoft の共有プラグイン レジストリに接続するようになり、メーカーはプラグイン、コネクタ、その他の利用可能な機能を簡単に見つけて使用できるようになりました。この統合により、Microsoft の AI エコシステム全体でエージェントの機能を拡張する、より一貫した方法が提供されます。

### 入力ボックスのコンテンツの簡素化

- 原題: Microsoft Copilot (Microsoft 365): Simplifying Content in the Input Box
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/10/10
- リリース段階: Launched
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=552592

ユーザーがプラス メニューの [作業コンテンツの追加] を使用してプロンプトにコンテンツを挿入すると、そのコンテンツは入力ボックス UI にピルとしてのみ表示され、ユーザーのプロンプトの一部として繰り返されません。これは、入力ボックスを簡素化し、プロンプト作成用に予約するのに役立ちます。 2026 年 4 月 22 日更新: これを移動します...

### Viva Engage - コミュニティ エージェント

- 原題: Microsoft Copilot (Microsoft 365): Viva Engage - Community Agent
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/10/10
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=499898

コミュニティ エージェントは、メンバーがコミュニティの知識と接続されたソースを使用して、Viva Engage コミュニティでの質問への回答を得るのを支援します。コミュニティ管理者は、回答が投稿される前に人によるレビューを要求するか、自動投稿を許可するかを選択できます。詳細: https://learn.microsoft.com/en-us/viva/engage/community-agent

### Copilot Studio でのコネクタの会話型構成

- 原題: Microsoft Copilot Studio: Conversational configuration of connectors in Copilot Studio
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/10/10
- リリース段階: Rolling out
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=569930

完全な設定エクスペリエンスではなく、単純なチャット内サインインを使用して、エージェントが必要とするコネクタを構成します。

### Dynamics 365 Supply Chain Management: 調達エージェント - 調達エージェントのサプライヤーのフォローアップ基準をカスタマイズします

- 原題: Dynamics 365 Supply Chain Management: Procurement Agent - Customize the Procurement Agent supplier follow-up criteria
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/10/10
- リリース段階: In development
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=573704

組織は多くの場合、ビジネス固有のデータと基準を使用して、サプライヤーが注文書のフォローアップを必要とする時期を決定します。調達エージェントを使用すると、バイヤーは関連する標準、拡張、およびカスタム テーブル データを使用してサプライヤーのフォローアップ基準を拡張できます。購入者はテーブル結合を追加し、そこからフィールドを使用できます。

### Dynamics 365 Sales: AI を活用したデータ エンリッチメントで使用するデータ ソース (CRM メモなど) を選択します

- 原題: Dynamics 365 Sales: Choose the data sources AI-powered Data Enrichment uses, including CRM notes
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/10/10
- リリース段階: Rolling out
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=574364

AI を活用したデータ強化により、管理者はエージェントがレコードを強化するために使用するデータ ソースを選択できるようになりました。 Outlook メール、Teams 会議、および新しい CRM ノート ソースにはそれぞれ独自の制御切り替えがあり、少なくとも 1 つのソースがオンになっている限りエージェントは実行され続けます。管理者は、毎回接続する必要がなくなります。

### Copilot によるスケジュール設定

- 原題: Microsoft Copilot (Microsoft 365): Scheduling with Copilot
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/10/10
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=573220

ユーザーはチャットから直接予定や会議をスケジュールできるようになりました。 Copilot に予定を作成するか、同僚との会議をスケジュールするよう依頼するだけで、利用可能な時間を検索し、部屋を予約し、議題の下書きを作成し、招待状を送信します。これらすべてがチャット エクスペリエンス内で行われます。
