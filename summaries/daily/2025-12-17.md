### Copilot for PowerPoint は、ストーリーの物語を構築するのに役立ちます

- 原題: Microsoft Copilot (Microsoft 365): Copilot for PowerPoint will help you build your story's narrative
- ソース: Microsoft 365 Roadmap
- 公開日: 2025/12/17
- リリース段階: Launched
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=518213

Copilot は、物語を形成し、それを完全にデザインされたスライドのプレゼンテーションに変えるのに役立ちます。

### Microsoft 365 管理センター: [エージェント] ページから SharePoint エージェントを管理する

- 原題: Microsoft 365 admin center: Manage SharePoint agents via Agents page
- ソース: Microsoft 365 Roadmap
- 公開日: 2025/12/17
- リリース段階: Launched
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=487857

管理者は、Microsoft 365 管理センターの [エージェント] ページで SharePoint エージェントを共有エージェントとして管理できます。エージェント インベントリから直接エージェントをブロック/ブロック解除できるようになります。
