## 全件

### Microsoft Copilot Studio でのエージェントの準備状況

- 原題: Microsoft Copilot Studio: Agent Readiness in Microsoft Copilot Studio
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/10/02
- リリース段階: Launched
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=568762

エージェント準備状況 により、メーカーは Copilot Studio エージェントのヘルス チェックをリアルタイムで常に確認できるようになります。ビルド エクスペリエンス内の 1 つの「レビュー」インジケーターは、ポリシーの制限から評価の欠落に至るまで、障害となっているものやリスクにさらされているものを、公開が妨げられる前に明らかにします。ブロックされた機能はグレー表示されます...

### Microsoft Teams でアプリ・エージェントのリンク展開を改善

- 原題: Microsoft Teams: Adaptive card-based app & copilot agent link unfurling in Teams
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/10/02
- リリース段階: Launched
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=515465

インコンテキスト ストアからチャットやチャネル内の SharePoint エージェントを検出して追加します。ユーザーは、名簿ドロップダウンから [エージェントとボットの追加] をクリックできます。これにより、インコンテキスト ストアが開き、ユーザーは SharePoint エージェントを見つけて会話に直接追加し、グループ内で共同作業することができます。 1月29日更新...

### Copilot Chat は、スキャンされた PDF からの検索結果とより適切に一致できるようになりました。

- 原題: Microsoft Copilot (Microsoft 365): Copilot Chat can now better match search results from Scanned PDFs
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/10/02
- リリース段階: Rolling out
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=559613

Copilot Chat は、スキャンされた PDF の検索結果と、Copilot ユーザーが作業中のファイル (以前は検索して見つけるのが困難だったコンテンツ) の検索結果をより正確に照合できるようになりました。この機能は、新規/更新されたユーザーの作業ファイルに対して今後も機能します。

### インテリジェントな通話委任

- 原題: Microsoft Teams: Intelligent call delegation
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/10/02
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=565216

Teams からの着信は、1 日の休憩を待つ必要はありません。インテリジェントな通話委任は AI を活用した通話支援を提供するため、最も重要な会話に集中できます。電話に応答してコンテキストを収集し、発信者に出て対応するかどうかを決定するのに役立ちます。フォローアップのスケジュールを設定することもできます...
