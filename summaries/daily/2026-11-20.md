## 全件

### セルフサービス同期コネクタ

- 原題: Microsoft Copilot (Microsoft 365): Self-serve sync connectors
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/11/20
- リリース段階: Retirement
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=568788

セルフサービス同期コネクタを使用すると、ユーザーは Jira や Confluence Cloud などの独自の外部データ ソースを Microsoft 365 Copilot に安全に接続できます。ユーザーは、自分の資格情報と権限を使用して、既にアクセス権を持っているコンテンツを同期し、Copilot Chat や Microsoft Search で検索できるようにすることができます。

### Webhook 主導の通知を備えた Copilot コネクタを使用してコンテンツの鮮度を向上

- 原題: Microsoft Copilot (Microsoft 365): Improved content freshness using Copilot connectors with webhooks-led notifications
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/11/20
- リリース段階: Retirement
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=505441

Copilot コネクタは、Webhook イベント通知を使用して更新をより頻繁に同期することで、コンテンツの鮮度を向上させます。 Azure DevOps、Jira クラウド、Confluence クラウド、Trello、Asana、Bitbucket、GitHub、Gitlab のコネクタが対象になります。

### PPAC レポート API

- 原題: Microsoft Copilot Studio: PPAC Reporting API
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/11/20
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=579968

Copilot クレジット用の Power Platform レポート API を使用すると、顧客は Power Platform API を介して Copilot Studio から Copilot クレジットの使用状況にアクセスできるようになり、Power Platform 管理センターで利用できる既存のレポートが拡張されます。 API メソッドの詳細については、Microsoft Power Platform API リファレンスを参照してください。

### ワークフローを共同所有者と共有して共同編集します

- 原題: Microsoft Copilot Studio: Share workflows with co-owners for collaborative editing
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/11/20
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=580864

作成者は、ワークフローを共同所有者として他のユーザーと共有し、ワークフローを表示、編集、管理できるようになります。ワークフロー ページまたはデザイナーから共有します。共有する前に、ワークフローが使用する接続とその権限を確認してください。共有を再度開くときに、ワークフローが誰と共有されているかを確認します。共同所有者は、...を編集して実行できます。
