## 全件

### Microsoft Copilot Studio での SQL サーバーのサポート

- 原題: Microsoft Copilot Studio: SQL server Support in Microsoft Copilot Studio
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/08
- リリース段階: In development
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=568930

Azure SQL ナレッジ ソース機能により、メーカーが Copilot Studio でエージェントを構築する際に活用できるエンタープライズ データ ソースの範囲が拡張されます。これにより、組織は、顧客と同じ知識中心のアプローチを使用して、Azure SQL に保存されているビジネス クリティカルな情報をエージェント エクスペリエンスに取り込むことができます。

### キュー アプリでの通話後に Copilot チャットを使用する

- 原題: Microsoft Teams: Use Copilot Chat after a call in Queues app
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/08
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=568933

録音された通話が完了したら、キュー アプリで Copilot を使用すると、トランスクリプトを手動で検索したり録音を聞き返したりすることなく、重要な詳細をすばやく把握し、洞察を明らかにし、顧客の問題をより迅速に解決できます。キュー アプリの統合通話履歴に移動し、記録された通話履歴を選択します。

### キュー アプリでのインテリジェントな通話の要約

- 原題: Microsoft Teams: Intelligent call recaps in Queues app
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/08
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=569017

通話録音に費やす時間を短縮して、顧客の問題をより迅速に解決します。録音された通話キューの通話について、キュー アプリは、AI が生成した要約メモ、重要な議論のポイント、フォローアップ アクションを含む、録音された通話のインテリジェントな通話要約をサポートするようになりました。キュー アプリの通話記録に移動して...

### Outlook の Copilot Chat は、受信トレイ、カレンダー、エンタープライズ データの推論に拡張されます。

- 原題: Microsoft Copilot (Microsoft 365): Copilot Chat in Outlook expands to reason over inbox, calendar, and enterprise data
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/08
- リリース段階: In development
- 役割タグ: 管理者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=554934

Outlook の Copilot Chat は、Microsoft 365 Copilot Chat ユーザー (Microsoft 365 Copilot ライセンスなし) のユーザーの受信トレイ全体、予定表、その他の企業データに対する推論をサポートするように拡張されています。
