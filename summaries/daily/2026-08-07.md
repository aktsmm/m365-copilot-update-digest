### Microsoft Copilot Studio でのエージェントの準備状況

- 原題: Microsoft Copilot Studio: Agent Readiness in Microsoft Copilot Studio
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/07
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=568762

エージェント準備状況により、メーカーは Copilot Studio エージェントのヘルス チェックをリアルタイムで常に確認できるようになります。ビルド エクスペリエンス内の 1 つの「レビュー」インジケーターは、ポリシーの制限から評価の欠落に至るまで、障害となっているものやリスクにさらされているものを、公開が妨げられる前に明らかにします。ブロックされた機能は前面にグレー表示されます...

### Copilot チャットのプランナー機能 (M365 Copilot)

- 原題: Microsoft Copilot (Microsoft 365): Planner capabilities in Copilot chat (M365 Copilot)
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/07
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=516577

M365 Copilot チャットで Planner タスクと Planner 情報をクエリする計画の作成をサポートし、ユーザーが Copilot と Planner の間でタスクと計画をシームレスに管理できるようにします。

### キュー アプリでの通話後に Copilot チャットを使用する

- 原題: Microsoft Teams: Use Copilot Chat after a call in Queues app
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/07
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=568933

録音された通話が完了したら、キュー アプリで Copilot を使用すると、トランスクリプトを手動で検索したり録音を聞き返したりすることなく、重要な詳細をすばやく把握し、洞察を明らかにし、顧客の問題をより迅速に解決できます。キュー アプリの統合通話履歴に移動し、記録された通話履歴を選択します。
