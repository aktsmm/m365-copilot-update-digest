### Copilot Analytics - Agent 365 ダッシュボードのエージェント価値に関する洞察

- 原題: Microsoft Viva: Copilot Analytics - Agent value insights in Agent 365 Dashboard
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/09/09
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=570847

お客様は、Microsoft Viva Insights (Copilot Analytics) の Agent 365 ダッシュボードで価値に関する洞察を表示できるようになりました。これらの洞察は、ビジネス リーダーや変更および導入のスペシャリストが、エージェントが使用されているかどうかだけでなく、エージェントが提供する推定支援時間や貢献する作業の種類も理解するのに役立ちます。
