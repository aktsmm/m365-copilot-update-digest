## 全件

### プランナー: Outlook で利用可能

- 原題: Planner: Available in Outlook
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/04
- リリース段階: In development
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=513278

Outlook の Planner は、すべてのタスク、計画、新しい Planner エージェントを受信トレイに直接取り込むため、すでに作業している場所で作業を管理できます。

### 自律的なビジネス プロセスのためのより強力なエージェントとワークフロー: Copilot Studio の新しいハーネスの導入

- 原題: More powerful agents and workflows for autonomous business processes: Introducing a new harness for Copilot Studio
- ソース: Copilot Studio Blog
- 公開日: 2026/08/04
- リリース段階: GA
- 役割タグ: 作成者向け
- URL: https://techcommunity.microsoft.com/t5/copilot-studio-blog/more-powerful-agents-and-workflows-for-autonomous-business/ba-p/4542969

過去 2 か月間、私たちは、より複雑なビジネス プロセスを処理できるエージェントを構築できる Copilot Studio 内の新機能をプレビューしてきました。本日、この機能が実稼働環境での一般利用が可能になり、導入されたことをお知らせできることを嬉しく思います。

### Viva Glint - Copilot 管理者構成支援

- 原題: Microsoft Viva: Viva Glint - Copilot admin configuration assistance
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/04
- リリース段階: In development
- 役割タグ: 管理者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=567320

Viva Glint 管理エクスペリエンスに組み込まれた Copilot を利用した会話型アシスタントは、構成やハウツーの質問に答え、段階的なガイダンスを提供します。応答には、ナビゲーションと発見性を合理化する設定ページへのディープ リンクが含まれます。管理者を持つ Viva Glint ユーザーのみが利用できます...

### Microsoft 365 Copilot アプリのブランド フッター

- 原題: Microsoft Copilot (Microsoft 365): Branded footer in the Microsoft 365 Copilot app
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/04
- リリース段階: Rolling out
- 役割タグ: 管理者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=555852

この更新プログラムでは、Microsoft 365 Copilot アプリに共同ブランド エクスペリエンスが導入され、組織が管理者によって承認された視覚的な識別子をチャット画面内に直接表示できるようになります。具体的には、このエクスペリエンスにより、管理者は Microsoft 管理ツールですでに管理されている組織でサポートされているロゴを活用できるようになります。

### アプリのスラッシュ コマンド

- 原題: Microsoft Teams: Slash commands for apps
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/04
- リリース段階: Rolling out
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=495002

スラッシュ コマンドを使用して、Teams チャットやチャネル作成ボックスからお気に入りのアプリを直接操作できるようになりました。 / と入力すると、アプリやエージェントとの対話が開始され、ワー​​クフローなどが呼び出されます。

### IT 管理者が通話の録音と文字起こしのためにユーザー通知メッセージをカスタマイズできる機能

- 原題: Microsoft Teams: Ability for IT admins to customize the user notification messages for recording and transcription in calls
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/04
- リリース段階: Rolling out
- 役割タグ: 管理者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=567302

この機能を使用すると、IT 管理者は、Teams 通話中の録音と文字起こしのためにユーザー通知メッセージの一部をカスタマイズできます。
