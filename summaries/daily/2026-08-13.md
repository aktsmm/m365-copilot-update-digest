### Copilot が文書構造を活用した長文ファイル ナビゲーションを強化

- 原題: Microsoft Copilot (Microsoft 365): Copilot improved long files navigation using document structure, enabling more accurate answers and clearer citations.
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/13
- リリース段階: Update
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=559614

Copilot が文書構造をより認識できるようにすることで、Copilot が長く複雑なファイルを読み取る方法を改善しました。質問すると、Copilot は回答する前に文書の最も関連性の高い部分 (特定のセクション/ページなど) に移動できるようになりました。これにより、詳細の見逃しが減り、明確な説明で信頼性が向上します。

### 翻訳ボタンで多言語の要約が利用可能

- 原題: Microsoft Teams: Multilingual recap available with translation button
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/13
- リリース段階: Rolling out
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=567458

会議中に選択した翻訳言語で会議の要約が自動的に生成されると、ユーザーは生成後に会議の要約の言語を引き続き変更できます。
