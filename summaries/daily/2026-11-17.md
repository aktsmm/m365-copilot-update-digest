## 全件

### エージェント ノードを使用してワークフロー ステップとしてエージェントを呼び出す

- 原題: Microsoft Copilot Studio: Invoke agents as workflow steps with the agent node
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/11/17
- リリース段階: Launched
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=562222

エージェント ノードをワークフローに追加すると、データの推論、ツールの呼び出し、応答の返しをすべて 1 つのステップ内で行うことができます。エージェント ノードを使用すると、推論をワークフローに直接埋め込むことができます。これは、手動の引き継ぎが減り、処理時間が短縮され、追加の開発を行わずに微妙な決定を処理できるワークフローを意味します。

### Confluence Cloud Copilot コネクタのクエリ フィルターの調整のサポート [Web]

- 原題: Support for refining query filters for the Confluence Cloud Copilot connector [Web]
- ソース: Microsoft 365 Copilot release notes
- 公開日: 2026/11/17
- リリース段階: Preview
- 役割タグ: 管理者向け / 作成者向け
- URL: https://learn.microsoft.com/en-us/microsoft-365/copilot/connectors/confluence-cloud-deployment#include-or-exclude-data

この機能により、管理者は Confluence Cloud コネクタのインデックスの内容をより詳細に制御できるようになります。デフォルトでは、コネクタはすべてのブログとページにインデックスを付けます。管理者は特定のスペースを含めたり除外したりできるようになりました。高度なシナリオでは、Confluence クエリ言語 (CQL) 文字列を作成できます。

- 役割タグ: 管理者向け / 作成者向け
