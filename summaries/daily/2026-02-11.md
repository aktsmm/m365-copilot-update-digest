## 全件

### Outlook の Copilot チャットを使用して電子メールを要約する

- 原題: Microsoft Copilot (Microsoft 365): Summarize email with Copilot chat in Outlook
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/02/11
- リリース段階: Launched
- 役割タグ: 管理者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=498320

Microsoft 365 Copilot ライセンスを持たないユーザーでも、Copilot チャットを使用して、ワンクリックでメールを簡単に要約できるようになりました。ユーザーが利用するには、Copilot チャットへのアクセスとピン留めが有効になっている必要があります。この変更は、従来の Windows 版 Outlook と新しい Windows 版 Outlook の両方に適用されます #newoutlookforwindows

### Microsoft 365 Copilot の連携機能を拡張

- 原題: Microsoft Copilot (Microsoft 365): Microsoft Copilot (Microsoft 365): Query Bitbucket Pull Requests with Copilot Connectors
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/02/11
- リリース段階: Launched
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=515163

お客様は、Copilot コネクタを使用して Microsoft 365 Copilot を Bitbucket に接続し、ナレッジ ベースのコンテンツをクエリしたりプル リクエストを実行できるようになりました。

### Finder で OneDrive ファイルで Copilot を使用する

- 原題: Microsoft Copilot (Microsoft 365): Use Copilot with OneDrive files in Finder
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/02/11
- リリース段階: Launched
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=527839

Microsoft 365 Copilot の機能を macOS での日常のファイル管理エクスペリエンスに直接導入します。この更新により、ユーザーは Finder で Copilot と対話して、OneDrive ファイルについて質問できるようになります。
