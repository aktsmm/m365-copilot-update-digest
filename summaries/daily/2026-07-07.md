## 全件

### 管理センターに GCC 向け Copilot Chat 使用状況レポートを追加

- 原題: Microsoft Copilot (Microsoft 365): Microsoft 365 admin center - Usage reports - Copilot Chat for GCC, GCC High and DoD
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/07/07
- リリース段階: In development
- 役割タグ: 管理者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=567121

Copilot Chat をカバーする新しい使用状況レポートを導入します。このレポートには、アクティブ ユーザーの合計、Microsoft 365 アプリごとのブレイクアウトを含む Copilot Chat の使用状況、およびユーザー レベルのアクティビティに関する分析情報 (既定では匿名化されています) が含まれます。 #copilotcontrolsystemGA 日付: 2026 年 7 月

### Microsoft 365 アプリ: Microsoft Loop - ユーザー所有のループ ワークスペースの離脱ユーザー コンテンツ ワークフロー

- 原題: Microsoft 365 app: Microsoft Loop - Departed user content workflows for user-owned Loop workspaces
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/07/07
- リリース段階: Launched
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=421612

ユーザーが組織を退職したときに、Copilot Pages などのユーザー所有の Loop ワークスペースの保持および削除のワークフローを管理します。削除ポリシーが有効になる前に、他の従業員または管理者に通知して、重要なデータを保存するための一時的なアクセスを提供します。

### Microsoft 365 Copilot の検索・チャットでデータ ソース表示をカスタマイズ可能に

- 原題: Microsoft Copilot (Microsoft 365): [Copilot Extensibility] [Search UX] Enable customization of icon &amp; name for data sources in Search (&amp; chat)
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/07/07
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=502532

検索 (およびチャット) でデータ ソースのアイコンと名前のカスタマイズを有効にします。

### Microsoft 365 アプリ: Microsoft 365 Copilot アプリの新しい Copilot ノートブック デザイン

- 原題: Microsoft 365 app: New Copilot Notebooks design in the Microsoft 365 Copilot App
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/07/07
- リリース段階: Rolling out
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=562662

Microsoft 365 Copilot アプリの新しい Copilot ノートブック デザインにより、ユーザーは関連するチャット、出力作成、参照を永続的な AI ワークスペースに整理できるようになりました。 Copilot はノートブックに蓄積されたコンテキストを使用して応答をグラウンディングするため、作業は毎回最初からやり直すのではなく、セッションをまたいで継続されます。この間...
