### Copilot Search は人々の発見に役立ちます

- 原題: Microsoft Copilot (Microsoft 365): Copilot Search Helps You Discover People
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/10/28
- リリース段階: Launched
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=555240

Copilot Search は、より広範な人々の検索クエリに対して一致する人々を返すことができるようになりました。連絡先となる既知の人物と新しい人物を発見、曖昧さを解消し、探索できるようにします。 「プロジェクト リーダーシップ」や「人工知能」などの特定のスキルを持つ人材を探している場合は、Copilot の検索が役に立ちます...

### 従来の Outlook の新しい Copilot エントリ ポイント

- 原題: Outlook: New Copilot entry point in Classic Outlook
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/10/28
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=567007

私たちは、アプリ内に Copilot の新しいエクスペリエンスを導入しました。これは、作業の上に位置し、その下にあるコンテキストを理解する、アプリ間での一貫したエントリ ポイントです。インターフェイス全体にタッチポイントを分散させるのではなく、Copilot を Microsoft 365 全体にわたる 1 つの接続されたシステムとして固定し、関連するアクションを表面化します。

### Copilot Chat と宣言型エージェントで Agent 365 エージェントを利用可能に

- 原題: Microsoft Copilot (Microsoft 365): Use Agent 365 agents within Microsoft 365 Copilot Chat and Declarative Agents
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/10/28
- リリース段階: Rolling out
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=567670

Agents 365 に公開されたエージェントは、Microsoft 365 管理センターですでに管理されています。エージェントが Agent2Agent プロトコルを実装している場合、ユーザーが Agent Builder または Copilot Studio で構築するエージェントの接続エージェントとして使用できます。

### Power Automate: AI 支援による UI オートメーションの修復

- 原題: Power Automate: AI-assisted UI Automation repair
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/10/28
- リリース段階: In development
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=577869

新しいエージェント デバッグ実行機能がフロー デザイナーで利用できるようになります。フローの実行中に UI 自動修復インターフェイスが起動し、フローで使用される各セレクターを検証します。次に、ユーザーがそれぞれの要素をキャプチャした後、既存のセレクターが期待どおりに機能しない場合に備えて、新しいセレクターを提案します。
