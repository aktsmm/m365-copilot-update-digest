## 全件

### Microsoft 365 Copilot の会議・チャット機能を更新

- 原題: Microsoft Copilot (Microsoft 365): Preview and chat with Word, Excel, and PowerPoint files in the Microsoft 365 Copilot app on Android
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/02/07
- リリース段階: Launched
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=518290

Android 上の Microsoft 365 Copilot アプリで Microsoft Word、Excel、または PowerPoint ファイルを開くと、ユーザーにはプレビュー エクスペリエンスが表示され、Microsoft Copilot チャットを使用して指示したり質問したりできるようになります。

### Copilot ダッシュボード - ベンチマーク

- 原題: Microsoft Viva: Copilot Dashboard - Benchmarks
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/02/07
- リリース段階: Launched
- 役割タグ: 管理者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=495464

Copilot のアクティブな使用状況を Copilot ダッシュボードのベンチマークと比較します。外部ベンチマークは、使用状況を他の企業と比較するための参考になります。内部ベンチマークにより、ユーザーは次のことを行うことができます。
