## 全件

### 強化された自動入力

- 原題: Microsoft Edge: Enhanced Autofill
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/09/18
- リリース段階: In development
- 役割タグ: 管理者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=554938

デスクトップ ユーザーの場合、Microsoft Edge では、保存された住所に加えて、パスポート、運転免許証、その他の特殊なフォームなどの追加の種類の書類を自動入力できるようになりました。

### 会議の共有ファイル

- 原題: Microsoft Teams: Meeting Shared Files
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/09/18
- リリース段階: In development
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=570427

新しい会議共有ファイル機能を使用すると、ユーザーは関連ファイルやリンクを会議に追加して簡単にアクセスでき、そのコンテンツをすべての会議参加者と自動的に共有できます。ファシリテーター エージェントと同様に、会議の AI はこれらのファイルを使用して、質問に答え、スキル機能を強化するためのターゲットを絞ったグラウンディングを行います...

### Copilot ダッシュボードで Copilot メトリックをエクスポートする

- 原題: Microsoft Copilot (Microsoft 365): Export Copilot metrics in the Copilot Dashboard
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/09/18
- リリース段階: In development
- 役割タグ: 管理者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=500872

これにより、ユーザーはレポート作成やより詳細な分析のために、Copilot ダッシュボードから行レベルの Copilot メトリクスをエクスポートできるようになります。

### 画像について Copilot に質問する

- 原題: Microsoft Edge: Ask Copilot about an image
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/09/18
- リリース段階: In development
- 役割タグ: 管理者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=566864

Edge の画像について Copilot に質問すると、ユーザーは Edge コンテキスト メニューから直接 Copilot に画像を送信することで、Web からの画像を即座に分析できるようになり、ブラウジング エクスペリエンスを離れることなく、簡単に質問したり、洞察を得たり、ビジュアル コンテンツを理解したりすることができます。管理者は、この機能の可用性を制御できます...
