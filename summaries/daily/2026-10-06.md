### Windows コンソールの Teams Rooms からのアドホック ルーム予約

- 原題: Microsoft Teams: Ad-hoc room reservation from Teams Rooms on Windows console
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/10/06
- リリース段階: Launched
- 役割タグ: 管理者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=548648

Windows コンソール上の Teams Rooms を使用すると、すぐに使用できる会議室をすぐに予約できるため、スケジュールの競合を回避し、中断のない自発的な会議を確保できます。 Teams Rooms Pro ライセンスが付与されたルームで利用できます。

### データ セキュリティ ポスチャ エージェントでの資格情報のスキャン

- 原題: Microsoft Purview: Credential Scanning in Data Security Posture Agent
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/10/06
- リリース段階: Retirement
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=558436

データ セキュリティ ポスチャ エージェントを、新しい資格情報スキャン機能で強化します。対象範囲内の場所にある露出した資格情報やデータ セキュリティ上のリスクを検出できます。エージェントにスキャン タスクを割り当て、進行状況を追跡し、優先度の高い検出結果に対応できます。選択したデータの場所がスキャン対象です。

### Copilot をニーズに合わせて調整することで、生産性を向上させます。

- ソース: Microsoft 365 Copilot release notes
- 公開日: 2026/10/06
- リリース段階: Update
- 役割タグ: 作成者向け
- URL: https://learn.microsoft.com/en-us/microsoft-365/copilot/release-notes?tabs=all#2026-10-06

これを試してください:
