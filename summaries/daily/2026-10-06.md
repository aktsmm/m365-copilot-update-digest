## 全件

### Windows コンソールの Teams Rooms からのアドホック ルーム予約

- 原題: Microsoft Teams: Ad-hoc room reservation from Teams Rooms on Windows console
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/10/06
- リリース段階: Launched
- 役割タグ: 管理者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=548648

Windows コンソール上の Teams Rooms を使用すると、すぐに使用できる会議室をすぐに予約できるため、スケジュールの競合を回避し、中断のない自発的な会議を確保できます。 Teams Rooms Pro ライセンスが付与されたルームで利用できます。

### Microsoft 365 Copilot アプリのブランド フッター

- 原題: Microsoft Copilot (Microsoft 365): Branded footer in the Microsoft 365 Copilot app
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/10/06
- リリース段階: Launched
- 役割タグ: 管理者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=555852

この更新プログラムでは、Microsoft 365 Copilot アプリに共同ブランド エクスペリエンスが導入され、組織が管理者によって承認された視覚的な識別子をチャット画面内に直接表示できるようになります。具体的には、このエクスペリエンスにより、管理者は Microsoft Admin で既に管理されている組織でサポートされているロゴを活用できるようになります。

### データ セキュリティ ポスチャ エージェントでの資格情報のスキャン

- 原題: Microsoft Purview: Credential Scanning in Data Security Posture Agent
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/10/06
- リリース段階: Retirement
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=558436

データ セキュリティ ポスチャ エージェントを、新しい資格情報スキャン機能で強化します。対象範囲内の場所にある露出した資格情報やデータ セキュリティ上のリスクを検出できます。エージェントにスキャン タスクを割り当て、進行状況を追跡し、優先度の高い検出結果に対応できます。選択したデータの場所がスキャン対象です。

### Copilot Analytics - エージェント ダッシュボード。

- 原題: Microsoft Viva: Copilot Analytics - Agent Dashboard.
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/10/06
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=506749

Viva Insights は、リーダー、代表者、アナリストが組織がエージェントをどのように採用しているかを理解するための中心となる場所となるように設計されたエージェント ダッシュボードを作成しています。 #copilotcontrolsystem

### インテリジェントな通話委任

- 原題: Microsoft Teams: Intelligent call delegation
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/10/06
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=565216

Teams からの着信は、1 日の休憩を待つ必要はありません。インテリジェントな通話委任は AI を活用した通話支援を提供するため、最も重要な会話に集中できます。電話に応答してコンテキストを収集し、発信者に出て対応するかどうかを決定するのに役立ちます。フォローアップのスケジュールを設定することもできます...
