## 全件

### PPAC レポート API

- 原題: Microsoft Copilot Studio: PPAC Reporting API
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/11/19
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=579968

PPAC Reporting API を使用すると、お客様は、レイクハウスから Copilot Studio の使用状況データにスケーラブルでプログラム的にアクセスできるようになり、サポートされていない古い消費データ取得方法に代わるものになります。環境、ユーザー、エージェント、機能ごとの毎日の JSON データは、ダッシュボード、FinOps レポート、自動化されたコスト管理を強化します。

### Copilot ワークスペースの更新

- 原題: Microsoft Copilot (Microsoft 365): Copilot Workspaces updates
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/11/19
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=579889

新しい Copilot ワークスペースのアップデートにより、Work IQ は現在のワークストリームに基づいて関連するワークスペースを提案し、ユーザーが迅速に作業を開始できるようにします。ワークスペースに入ると、チーム メンバーは共有ドキュメントで共同作業でき、同時に Copilot が作業全体の点を結び、何が変更されたのか、何が未解決のままなのかを明らかにします。
