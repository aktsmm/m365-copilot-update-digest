## 全件

### Confluence Copilot コネクタのクエリ フィルターの調整のサポート

- 原題: Microsoft Copilot (Microsoft 365): Support for refining query filters for Confluence Copilot connectors
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/11/04
- リリース段階: Launched
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=503571

この機能は、Confluence Cloud コネクタと Confluence オンプレミス コネクタの両方にわたるクエリ フィルタリングを強化および標準化します。 Confluence Cloud コネクタでは、フィルタリングするための簡素化されたオプションが導入されています。

### Power Automate を使用して SharePoint のフォームを使用してドキュメントを生成する

- 原題: Microsoft Copilot (Microsoft 365): Generate documents using forms in SharePoint with Power Automate
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/11/04
- リリース段階: Launched
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=561026

SharePoint のドキュメント生成 (DocGen) フォームを使用した自動ドキュメント生成を可能にする、新しい Power Automate アクションを導入します。フォームからドキュメントを生成 (プレビュー) を使用すると、データ入力を事前定義されたテンプレート フィールドにマッピングすることで、テンプレートからドキュメントを作成できます。ドキュメントは次のように生成されます。
