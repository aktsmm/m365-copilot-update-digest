### Microsoft 365 Copilot の更新

- 原題: Microsoft Copilot (Microsoft 365): Copilot uses enterprise assets hosted on SharePoint OAL or Templafy when creating a slide
- ソース: Microsoft 365 Roadmap
- 公開日: 2025/12/16
- リリース段階: Launched
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=496365

組織の資産が SharePoint 組織資産ライブラリ (OAL) に統合されるか、Templafy 経由で Microsoft 365 Copilot に接続されると、次のツールを使用してスライドを簡単に作成できるようになります。

### マルチテナント設定で利用できるインテリジェントな会議の要約

- 原題: Microsoft Teams: Intelligent meeting recap available in multi-tenant set ups
- ソース: Microsoft 365 Roadmap
- 公開日: 2025/12/16
- リリース段階: Launched
- 役割タグ: 管理者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=488298

B2B マルチテナント組織セットアップの Copilot ユーザーは、会議がホストされたリソース テナントから会議後にインテリジェントな会議の概要を表示できるようになりました。
