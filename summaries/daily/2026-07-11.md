## 全件

### Microsoft 365 Copilot の連携機能を拡張

- 原題: Microsoft Copilot (Microsoft 365): Frontier and Microsoft agent user request approval flow in Microsoft 365 admin center
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/07/11
- リリース段階: Launched
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=494809

管理者の場合、Frontier プログラムのエージェントは Microsoft 365 管理センターを通じて管理できます。これらは Copilot Control System の [エージェントとコネクタ] タブにリストされており、組織のすべてのエージェント インベントリを表示できます。 Microsoft によって構築され、Frontier プログラムで利用可能なエージェントが表示されます...

### エージェントまたはアプリによって呼び出されるフローのエクスプレス モードを有効にする

- 原題: Microsoft Copilot Studio: Enable express mode for flows invoked by an agent or app
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/07/11
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=566999

高速モードでは、フローの実行時間を大幅に短縮することで、エージェントとアプリがタイムリーで信頼性の高い応答を受け取ることができます。これにより、フローの障害が減少し、ユーザー エクスペリエンスが向上し、タイムアウトの問題によるコストのかかる中断が排除されます。組織は、より信頼性の高い自動化、導入率の向上、スムーズな処理から恩恵を受けます...

### 進行中の（共同）作業

- 原題: (Co)work in Progress
- ソース: Microsoft 365 Copilot Blog
- 公開日: 2026/07/11
- リリース段階: GA
- 役割タグ: 作成者向け
- URL: https://techcommunity.microsoft.com/t5/microsoft-365-copilot-blog/co-work-in-progress/ba-p/4511672

Microsoft 365 Copilot Cowork をチームのプレイブックに提供します。プラグインは組織のスキルと知識を 1 つのワークフローに統合するため、Cowork はサポート チームがすでに行っている方法で作業できるように支援します。 Frontier で Copilot Cowork を試す
簡単に言うと、コネクタは、次のことを可能にする「橋」です。

### ドキュメントとページの AI 引用分析

- 原題: SharePoint: AI citations analytics for documents and pages
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/07/11
- リリース段階: In development
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=480725

AI 引用分析は、Copilot と AI エージェントを通じて SP ドキュメント、ニュース、ページの使用状況を追跡するのに役立ちます。Copilot の応答でページまたはファイルが参照される頻度を確認できます。また、サイトで集約された Copilot の応答で参照されている SharePoint サイトのコンテンツについての洞察を得ることができます。

### フォームを使用した構造化ドキュメントの生成

- 原題: Microsoft Copilot (Microsoft 365): Structured Document Generation with Forms
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/07/11
- リリース段階: In development
- 役割タグ: 管理者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=545896

フォームを使用した構造化ドキュメントの生成により、組織は SharePoint に組み込まれたガバナンスとコンプライアンスを利用して、大規模な標準化されたドキュメントを作成、管理、生成できます。ビジネス プロセスの所有者は、契約書、同意書、提案書、人事文書などのフォームベースのテンプレートを一元的に構築および維持できます。
