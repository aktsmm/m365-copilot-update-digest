### Microsoft 365 管理センター: エージェント所有権の再割り当て

- 原題: Microsoft 365 admin center: Agent Ownership Reassignment
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/01/09
- リリース段階: Launched
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=502867

管理者は、Copilot Studio や Microsoft 365 Agents Toolkit などのツールを使用して、組織内で作成された共有エージェントの所有権を再割り当てできます。再割り当てされると、新しい所有者は完全な権限を取得します。
