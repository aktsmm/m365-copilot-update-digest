## 全件

### データ セキュリティ体制管理 - DSPM のデータ セキュリティ体制エージェント

- 原題: Microsoft Purview: Data Security Posture Management-Data Security Posture Agent in DSPM
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/11
- リリース段階: Launched
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=542790

データ セキュリティ体制エージェント は、組織内の動的なデータとリスクの状況を常に把握するために積極的に取り組むデータ セキュリティ管理者の能力を拡張するように設計されています。その主な仕事は、データ資産全体にわたる機密データの検出を支援することです。このエージェントは、ドキュメントを分析および検索するように設計されています。

- 原題: Microsoft Copilot (Microsoft 365): Outlook Emails in Copilot Notebooks
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/11
- リリース段階: Launched
- 役割タグ: 作成者向け

Copilot ノートブック の参照としての Outlook 電子メールは、電子メールのコンテンツをノートブックのエクスペリエンスに取り込み、ユーザーが仕事を推進する会話、意思決定、コンテキストに Copilot を定着させることができるようにします。電子メールを知識ソースとして追加することで、ユーザーは電子メールのコンテキストをプロジェクトに直接接続し、内容を充実させることができます。

Dataverse を Copilot Studio のネイティブ ナレッジ ソースとして有効にし、構造化されたエンタープライズ データに AI エージェントを組み込むプラットフォームの機能を拡張します。この機能強化により、組織は、レコード、顧客データ、運用データなど、Dataverse に保存されているビジネスクリティカルな情報を活用できるようになります。

### 政府機関向けクラウドのプロンプトを保護するための Microsoft 365 Copilot のデータ損失防止

- 原題: Microsoft Purview: Data Loss Prevention for Microsoft 365 Copilot to safeguard prompts for government clouds
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/11
- リリース段階: Launched
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=561892

機密データを含むプロンプトを保護するために、Microsoft Purview DLP for Microsoft 365 Copilot を拡張しています。このリアルタイム制御は、プロンプトに機密データが含まれている場合やユーザーが要求した場合に Microsoft 365 Copilot と Copilot Chat が応答を返さないようにすることで、組織がデータ漏洩と過剰共有のリスクを軽減するのに役立ちます。

### OneDrive iOS の Copilot コンテキスト メニューを使用して PDF をレビューする

- 原題: Microsoft Copilot (Microsoft 365): Review PDFs using the Copilot context menu on OneDrive iOS
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/11
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=568790

Microsoft 365 Copilot を使用すると、モバイル上で PDF レビューを迅速かつ簡単に行うことができます。 OneDrive iOS の PDF 内のテキストを選択し、[Ask Copilot] をタップすると、選択内容について説明、要約、翻訳、またはカスタムの質問をすることができます。これと同じコンテキスト内での Copilot エクスペリエンスがデスクトップですでに一般提供されており、今度は OneDrive iOS でも提供されます。
