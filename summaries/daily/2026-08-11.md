- 原題: Microsoft Purview: Data Security Posture Management-Data Security Posture Agent in DSPM

- リリース段階: Launched
- 役割タグ: 管理者向け / 作成者向け

データ セキュリティ体制エージェント は、組織内の動的なデータとリスクの状況を常に把握するために積極的に取り組むデータ セキュリティ管理者の能力を拡張するように設計されています。その主な仕事は、データ資産全体にわたる機密データの検出を支援することです。このエージェントは、ドキュメントを分析および検索するように設計されています。

### 政府機関向けクラウドのプロンプトを保護するための Microsoft 365 Copilot のデータ損失防止

- 原題: Microsoft Purview: Data Loss Prevention for Microsoft 365 Copilot to safeguard prompts for government clouds

- 公開日: 2026/08/11
- リリース段階: Launched
- 役割タグ: 管理者向け / 作成者向け
