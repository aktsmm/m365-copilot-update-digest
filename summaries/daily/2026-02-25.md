### Microsoft Copilot (Microsoft M365): Copilot のコンテキスト メニューと AI アクションを使用して PDF をレビューする

- 原題: Microsoft Copilot (Microsoft M365): Review PDFs using Copilot context menu and AI actions
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/02/25
- リリース段階: Launched
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=536574

Copilot を使用すると、PDF レビューを迅速かつ簡単に行うことができます。選択したテキストを平易な言語で説明し、結果に応じてプロンプトをカスタマイズできるため、アプリを切り替える時間が短縮されます。

### Copilot はデフォルトで Word でドキュメントを編集できます

- 原題: Microsoft Copilot (Microsoft 365): Copilot can edit your document by default in Word
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/02/25
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=557673

Word での Copilot とのデフォルトのチャット エクスペリエンスでは、Copilot がドキュメントを直接編集できるようになりました。 Copilot によって行われたすべての変更は完全にレビュー可能で元に戻すことができ、ユーザーは必要に応じてこのエクスペリエンスをオフにすることができます。
