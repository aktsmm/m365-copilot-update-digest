## 全件

### アップグレードされた Copilot の新しいタブ ページ

- 原題: Microsoft Edge: Upgraded Copilot new tab page
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/19
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=566703

Copilot が提案するアクションや厳選された作業コンテンツを使用して 1 つの検索ボックスから Web を検索、チャット、探索できるため、ユーザーは Copilot の新しいタブ ページで作業を迅速に完了できます。ユーザーには、アップグレードされた Copilot の新しいタブ ページの機能が表示されます。

### Microsoft 365 Copilot のフェデレーション Copilot コネクタ

- 原題: Microsoft Copilot (Microsoft 365): Federated Copilot Connectors in Microsoft 365 Copilot
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/19
- リリース段階: In development
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=569212

Federated Copilot コネクタを使用すると、ユーザーは Microsoft Copilot をお気に入りのサードパーティ ソースに安全に接続し、Model Context Protocol (MCP) を使用してリアルタイムでデータを取得できます。 Federated Copilot コネクタは、Microsoft に顧客データを保存したりインデックスを作成したりしません。アクセスはユーザー自身の ID を使用してリアルタイムで行われます。

### 強化された Copilot チャットの概要

- 原題: Microsoft Teams: Enhanced Copilot chat summary
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/19
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=501201

多くのメッセージを見逃していませんか? Copilot はチャット会話内の新しいメッセージの概要を自動的に生成するため、すべてのメッセージを読まなくてもすぐに内容を理解できます。
