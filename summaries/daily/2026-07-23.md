## 全件

### 従来の Outlook の新しい Copilot エントリ ポイント

- 原題: Outlook: New Copilot entry point in Classic Outlook
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/07/23
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=567007

アプリ内に Copilot の新しいエクスペリエンスを導入しました。これは、作業の上に位置し、その下にあるコンテキストを理解する、アプリ間での一貫したエントリ ポイントです。インターフェイス全体にタッチポイントを分散させるのではなく、Copilot を Microsoft 365 全体にわたる 1 つの接続されたシステムとして固定し、役立つ関連アクションを表面化します。

### Excel で Copilot を使用して編集 (Web、Win32、Mac) - GCC

- 原題: Microsoft Copilot (Microsoft 365): Edit with Copilot in Excel (Web, Win32, Mac) - GCC
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/07/23
- リリース段階: In development
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=542181

Edit with Copilot では、Copilot と並行してワークブックを構築および編集できます。予算の更新、財務モデルの作成、またはデータの分析を行う場合、Copilot は表、グラフ、ピボットテーブル、数式などの Excel の最も強力なツールを使用して、作業を完了するのに役立ちます。
