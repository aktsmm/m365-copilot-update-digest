### アップグレードされた Copilot の新しいタブ ページ

- 原題: Microsoft Edge: Upgraded Copilot new tab page
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/07/17
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=566703

Copilot が提案するアクションや厳選された作業コンテンツを使用して 1 つの検索ボックスから Web を検索、チャット、探索できるため、ユーザーは Copilot の新しいタブ ページで作業を迅速に完了できます。ユーザーには、アップグレードされた Copilot の新しいタブ ページの機能と特長が表示されます。

### M365 Copilot でのセッションと応答の共有

- 原題: Microsoft Copilot (Microsoft 365): Session and Response Sharing in M365 Copilot
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/07/17
- リリース段階: In development
- 役割タグ: 管理者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=562353

### Teams の Copilot は、会議中に画面上で共有されたコンテンツを分析できます

- 原題: Microsoft Teams: Copilot in Teams can analyze content shared on-screen during a meeting
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/07/17
- リリース段階: Update
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=325873

Teams の Copilot は、録画が有効になっている場合、会議中に画面上で共有されたコンテンツを分析できます。これにより、会議記録や会議チャットと合わせて、ユーザーは Copilot に画面共有コンテンツから特定の情報 (例: 「最も売上が高かった製品はどれですか?」など) を要約または検索して、洞察を統合することができます。
