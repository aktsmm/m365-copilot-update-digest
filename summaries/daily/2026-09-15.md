### Windows 版従来の Outlook の Copilot 設定

- 原題: Outlook: Copilot Settings in classic Outlook for Windows
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/09/15
- リリース段階: Launched
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=561491

従来の Windows 版 Outlook でさまざまな Copilot 設定に直接アクセスできるようになります。

### Microsoft 365 Copilot アプリ (iOS) の Copilot ノートブックを刷新

- 原題: Microsoft 365 app: New Copilot Notebooks design in the Microsoft 365 Copilot App (iOS)
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/09/15
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=566318

Microsoft 365 Copilot アプリ (iOS) の Copilot ノートブックを使用すると、ユーザーは関連するチャット、出力作成、参照を永続的な AI ワークスペースに整理できるようになりました。 Copilot はノートブックに蓄積されたコンテキストを使用して応答をグラウンディングするため、作業は毎回最初からやり直すのではなく、セッションをまたいで継続されます。

### 従来の Outlook の新しい Copilot エントリ ポイント

- 原題: Outlook: New Copilot entry point in Classic Outlook
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/09/15
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=567007

アプリ内に Copilot の新しいエクスペリエンスを導入しました。これは、作業の上に位置し、その下にあるコンテキストを理解する、アプリ間での一貫したエントリ ポイントです。インターフェイス全体にタッチポイントを分散させるのではなく、Copilot を Microsoft 365 全体にわたる 1 つの接続されたシステムとして固定し、役立つ関連アクションを表面化します。

- リリース段階: Launched
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=501111

GCC-M のユーザーはカスタム エンジン エージェントを使用できるようになります。
