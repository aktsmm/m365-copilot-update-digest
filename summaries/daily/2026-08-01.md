## 全件

### 強化された自動入力

- 原題: Microsoft Edge: Enhanced Autofill
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/01
- リリース段階: In development
- 役割タグ: 管理者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=554938

デスクトップ ユーザーの場合、Microsoft Edge では、保存された住所に加えて、パスポート、運転免許証、その他の特殊なフォームなどの追加の文書タイプを自動入力できるようになりました。

### Copilot ノートブックでのマルチモーダル キャプチャ (Windows)

- 原題: OneNote: Multimodal capture in Copilot Notebooks (Windows)
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/01
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=566322

Windows の Capture を使用すると、会議、ブレーンストーミング セッション、日常業務から得た会話やアイデアを Copilot ノートブックに取り込むことができます。音声、画像、メモを 1 つのエクスペリエンスでキャプチャし、Copilot がそれらを重要な洞察、意思決定、アクション アイテムを含む構造化されたメモに変換して、Copilot ノートブックに保存します。

### Google 向け Work Search バナー

- 原題: Microsoft Edge: Work Search Banner for Google
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/01
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け

ユーザーが仕事用プロファイルから google.com で検索を実行すると、Microsoft Edge はそのクエリに対して組織固有の結果が利用可能かどうかを検出できます。関連する結果が見つかると、Microsoft 365 Copilot でそれらの作業結果を探索するためのリンク付きのバナーが表示されます。これは既存の経験に基づいて構築されます...
