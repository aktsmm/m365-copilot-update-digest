### 通訳および多言語会議エクスペリエンスの強化

- 原題: Microsoft Teams: Enhancements to Interpreter and multilingual meeting experience
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/01/07
- リリース段階: Launched
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=520389

まず、通訳が有効になっている場合、音声言語が自動的に検出され、通訳、ライブ キャプション、ライブ トランスクリプションにわたって更新されるようになり、すべての音声機能が言語との一貫性を維持します。

### Microsoft 365 Copilot Chat - GCC High 環境の一般提供

- 原題: Microsoft Copilot (Microsoft 365): Microsoft 365 Copilot Chat - General Availability for the GCC High environment
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/01/07
- リリース段階: Launched
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=509107

Microsoft 365 Copilot Chat は GCC High 環境で一般提供され、デフォルトで Web グラウンディングがオフになった状態で提供されます。これは、米国政府の機密情報を保護するために必要です...

### Microsoft 365 Copilot - GCCH 環境の AI アシスタント

- 原題: Microsoft Copilot (Microsoft 365): Microsoft 365 Copilot - your AI assistant in the GCCH environment
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/01/07
- リリース段階: Launched
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=509108

Microsoft 365 Copilot を GCC-H 環境での作業に AI アシスタントとして活用します。大規模言語モデルの機能と作業内容およびコンテキストを組み合わせて、下書きや書き直しを支援します。
