## 全件

### Microsoft 365 と Teams 管理センターにわたる統合エージェントとアプリの可用性管理

- 原題: Microsoft Teams: Unified Agent and App Availability Management Across Microsoft 365 and Teams Admin Center
- ソース: Microsoft 365 Roadmap
- 公開日: 2025/11/13
- リリース段階: Rolling out
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=503105

Microsoft 365 管理センターと Teams 管理センターを使用し、Teams、Outlook、Microsoft 365 Copilot 間で動作するエージェントとアプリを管理する管理者は、変更を適用できるようになります。

### Copilot Chat ContextIQ メニューでの作業コンテキストの提案

- 原題: Microsoft Copilot (Microsoft 365): Work context suggestions in Copilot Chat ContextIQ menu
- ソース: Microsoft 365 Roadmap
- 公開日: 2025/11/13
- リリース段階: Rolling out
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=481135

Copilot Chat は、プロンプトに入力すると、アクセスできるプロンプトと作業コンテキストを提案し、会話に関連する情報を見つけるのに役立ちます。
