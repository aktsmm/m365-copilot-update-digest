### Excel で Copilot を使用して編集 (Web、Win32、Mac) - GCC

- 原題: Microsoft Copilot (Microsoft 365): Edit with Copilot in Excel (Web, Win32, Mac) - GCC
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/11/03
- リリース段階: Launched
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=542181

Edit with Copilot では、Copilot と並行してワークブックを構築および編集できます。予算の更新、財務モデルの作成、またはデータの分析を行う場合、Copilot は表、グラフ、ピボットテーブル、数式などの Excel の最も強力なツールを使用して、作業を完了するのに役立ちます。

### Microsoft Cowork で Planner のプラン・タスク管理に対応

- 原題: Planner: Capabilities in Microsoft Cowork
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/11/03
- リリース段階: Rolling out
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=567315

Microsoft Planner を Microsoft Cowork に間もなく導入できるようになります。 Cowork では、アプリを切り替えることなく、計画、バケット、目標、タスクを表示、作成、更新できます。 Cowork は、ドラフトやメールの送信など、Microsoft 365 全体で Planner タスクの実行を支援することでさらに一歩進んでいます。

### Teams で AI 生成の会議アーカイブに対応

- 原題: Microsoft Teams: AI-generated meeting memory for knowledge retention (formerly AI-generated meeting archive)
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/11/03
- リリース段階: In development
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=558933

Teams は、Intelligent Recap がオンになっている会議の AI 生成の会議メモリ ファイルを保存するため、Copilot (およびファシリテーター) は、トランスクリプトの保存期間を超えた場合やトランスクリプトが保存されていない場合でも、会議からの重要な洞察を保持できるようになります。これにより、Copilot は過去に関する質問に回答し続けることができます。
