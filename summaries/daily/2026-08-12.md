## 全件

### Microsoft 365 管理センター: エージェントの使用状況レポート

- 原題: Microsoft 365 admin center: Agents usage report
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/12
- リリース段階: Launched
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=497999

新しいエージェント使用状況レポートは、Microsoft 365 管理センターで利用できるようになります。レポートの範囲は、M365 Copilot のライセンスを持つユーザーとライセンスのないユーザーの両方による使用に関する M365 Copilot および Copilot Chat のエージェントを含みます。レポートには、アクティブ エージェント ユーザーの合計、アクティブ エージェントの合計、アクティブ ユーザーのセグメント別...が含まれます。

### Copilot ノートブックでの Teams ミーティング

- 原題: Teams Meetings in Copilot Notebooks
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/12
- リリース段階: Launched
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=560706

Copilot ノートブック の参照としての会議は、Teams の会議コンテンツをノートブックのエクスペリエンスに取り込み、ユーザーが仕事を推進するディスカッション、意思決定、コンテキストに基づいて Copilot を実行できるようにします。会議をナレッジ ソースとして追加することで、ユーザーはトランスクリプト、メモ、チャット、共有コンテンツを会議に直接接続できます。

### Copilot ノートブック の CSV および TSV 参照

- 原題: Microsoft Copilot (Microsoft 365): CSV and TSV references in Copilot Notebooks
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/12
- リリース段階: In development
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=569210

Copilot ノートブック は、CSV および TSV ファイルをナレッジ ソースとしてサポートするようになりました。これにより、ユーザーは従来のドキュメントと並行して、構造化されたリストやテーブルをプロジェクトに直接取り込むことができます。この追加のコンテキストは、Copilot がより関連性の高いプレゼンテーション、レポート、概要を生成するのに役立ちます。

- リリース段階: In development

Copilot ノートブック は JPG および PNG ファイルをナレッジ ソースとしてサポートするようになり、ユーザーは従来のドキュメントと一緒に画像をプロジェクトに直接取り込むことができます。 Copilot は、テキスト、チャート、図、その他のビジュアルを含むこれらの画像内のコンテンツを基礎コンテキストとして使用して、より関連性の高い画像を生成できます。

### Microsoft 365 Copilot アプリの新しい Copilot ノートブック デザイン (DoD、GCC、GCC High)

- 原題: OneNote: New Copilot Notebooks design in the Microsoft 365 Copilot app (DoD, GCC, GCC High)
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/12
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=569203

DoD、GCC、および GCC High クラウド用の Microsoft 365 Copilot アプリの新しい Copilot ノートブック デザインにより、ユーザーは関連するチャット、出力作成、参照を永続的な AI ワークスペースに整理できるようになりました。 Copilot は、ノートブックの蓄積されたコンテキストを使用して応答をグラウンディングするため、作業はセッション間ではなくセッション間で継続されます。

### Copilot ページで Copilot から実用的な提案を取得します

- 原題: Microsoft Copilot (Microsoft 365): Get actionable suggestions from Copilot in your Copilot Page
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/12
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=562351

Copilot の [ショートカット] メニューの [編集の提案] を選択して、ページ上で Copilot からのフィードバックをリクエストします。 Copilot はページ上のコンテンツを分析し、書かれたコンテンツの明瞭さと品質を向上させるために何を変更できるかについて実用的な提案を提供します。その後、提案をページに直接適用できます。

- 原題: Microsoft Copilot (Microsoft 365): Add Agents and Skills from the Plus menu
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/12
- リリース段階: In development

ユーザーは、特殊なタスクのプロンプトにエージェントとスキルを挿入できるようになります。プラス (+) メニューから [作業内容の追加] を選択した後、[エージェントとスキル] タブから追加できます。ユーザーは、プロンプトに / と @ を入力して、エージェントとスキルにアクセスすることもできます。
