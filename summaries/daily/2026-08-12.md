## 全件

### Microsoft 365 管理センター: エージェントの使用状況レポート

- 原題: Microsoft 365 admin center: Agents usage report
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/12
- リリース段階: Launched
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=497999

Microsoft 365 管理センターで、M365 Copilot と Copilot Chat のエージェント使用状況を確認できる新しいレポートを提供。ライセンス有無別のアクティブ ユーザー数、アクティブなエージェント数、ユーザーの内訳を確認できます。

### Copilot ノートブックでの Teams ミーティング

- 原題: Teams Meetings in Copilot Notebooks
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/12
- リリース段階: Launched
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=560706

Copilot ノートブックで Teams 会議をナレッジ ソースとして参照可能に。トランスクリプト、メモ、チャット、共有コンテンツを基に、会議の議論や決定事項に沿った Copilot の応答を得られます。

### Copilot ノートブックで CSV・TSV ファイルを参照可能に

- 原題: Microsoft Copilot (Microsoft 365): CSV and TSV references in Copilot Notebooks
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/12
- リリース段階: In development
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=569210

Copilot ノートブックで CSV・TSV ファイルをナレッジ ソースとして参照可能に。構造化されたリストや表をプロジェクトに取り込み、より関連性の高いプレゼンテーション、レポート、概要を作成できます。

### Copilot ノートブックで JPG・PNG ファイルを参照可能に

- 原題: Microsoft Copilot (Microsoft 365): JPG and PNG references in Copilot Notebooks
- ソース: Microsoft 365 Roadmap

- リリース段階: In development
- 役割タグ: 作成者向け

Copilot ノートブックで JPG・PNG ファイルをナレッジ ソースとして参照可能に。画像内のテキスト、グラフ、図などをコンテキストとして活用し、より関連性の高い出力を生成できます。

### DoD・GCC・GCC High 向け Copilot ノートブックの新デザイン

- 原題: OneNote: New Copilot Notebooks design in the Microsoft 365 Copilot app (DoD, GCC, GCC High)
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/12
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=569203

DoD、GCC、GCC High 向け Microsoft 365 Copilot アプリで Copilot ノートブックの新デザインを提供。関連するチャット、作成物、参照を永続的な AI ワークスペースに整理し、蓄積したコンテキストをセッションをまたいで活用できます。

### Copilot Pages で実用的な編集提案を取得可能に

- 原題: Microsoft Copilot (Microsoft 365): Get actionable suggestions from Copilot in your Copilot Page
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/12
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=562351

Copilot Pages の [ショートカット] メニューから [編集の提案] を選ぶと、Copilot がページ内容を分析し、文章の明瞭さや品質を改善するための具体的な提案を表示します。提案はページに直接適用できます。

### SharePoint で HTML ページを作成・公開可能に

- 原題: SharePoint: HTML pages
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/12
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=569208

SharePoint で Copilot を使って HTML ページを作成したり、外部で作成した HTML をアップロードしたりできます。ページ ライブラリに保存後、SharePoint ページとして表示、編集、共有でき、既存の ASPX ページと並べて表現の幅を広げられます。

### Copilot のプラス メニューからエージェントとスキルを追加可能に

- 原題: Microsoft Copilot (Microsoft 365): Add Agents and Skills from the Plus menu
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/12
- リリース段階: In development
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=569213

Copilot のプラス (+) メニューから [作業内容の追加] を選び、[エージェントとスキル] タブで専用タスク向けのエージェントやスキルをプロンプトに追加できます。/ や @ の入力でも呼び出せます。
