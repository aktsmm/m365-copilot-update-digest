### Clipchamp スタート ページでビデオを作成する

- 原題: Microsoft Copilot (Microsoft 365): Create Videos in the Clipchamp Start Page
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/09/05
- リリース段階: Launched
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=553215

Clipchamp スタート ページから Copilot でビデオを作成できます。プロンプトや既存のドキュメントを基に、スクリプト、ビジュアル、ナレーションを含むビデオを自動生成できます。

### 現在利用可能: Microsoft Copilot の OpenAI GPT-6 Astra

- 原題: Available today: OpenAI GPT-6 Astra in Microsoft Copilot
- ソース: Microsoft 365 Copilot Blog
- 公開日: 2026/09/05
- リリース段階: Rolling out
- 役割タグ: 作成者向け
- URL: https://techcommunity.microsoft.com/t5/microsoft-365-copilot-blog/available-today-openai-gpt-6-astra-in-microsoft-copilot/ba-p/4552808
