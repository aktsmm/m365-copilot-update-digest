## 全件

### SharePoint リスト エージェント

- 原題: Microsoft Copilot (Microsoft 365): SharePoint list agent
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/03/17
- リリース段階: Launched
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=534606

インテリジェントなスキーマ生成とセットアップにより、プロンプトを通じて Copilot ユーザーが簡単にリストを作成できるようになります。このエージェントは、チームが構造化情報と Copilot の応答を Microsoft リストに迅速に変換するのに役立ちます。

### Microsoft 365 管理センター: M365 Copilot - 請求と使用状況 - 使用状況の分析情報

- 原題: Microsoft 365 Admin Center: M365 Copilot - Billing and usage - Usage insights
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/03/17
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=492616

M365 Copilot Chat の従量課金制を有効にすると、AI 管理者は使用状況の分析情報を表示して、エージェント管理の決定を通知できます。この機能は、合計およびエージェントごとのメッセージのコストと数を表示します。コストと使用量の詳細は、請求ポリシーと日付範囲によってフィルタリングできます。

### IT を制御しながら、エージェントがアプリを業務フローに取り込めるようにする

- 原題: Enable agents to bring apps into the flow of work—while keeping IT in control
- ソース: Microsoft 365 Copilot Blog
- 公開日: 2026/03/17

- URL: https://techcommunity.microsoft.com/t5/microsoft-365-copilot-blog/enable-agents-to-bring-apps-into-the-flow-of-work-while-keeping/ba-p/4499464
