### Microsoft 365 管理センター: Copilot - 請求と使用量 - プリペイド キャパシティ パック クレジットのスタンドアロン消費

- 原題: Microsoft 365 admin center: Copilot - Billing and usage - Standalone consumption of prepaid capacity pack credits
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/02/19
- リリース段階: In development
- 役割タグ: 管理者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=557175

サポートされている Copilot エクスペリエンスの唯一の請求方法として、プリペイド キャパシティー パックを使用してください。管理者は、プリペイド容量を使用した請求ポリシーを構成して、ポリシー内のユーザーの使用量がプリペイド容量クレジットからのみ差し引かれるように、従量課金制なしで構成できます。

### Microsoft Edge の会議・チャット機能を更新

- 原題: Microsoft Edge: Summarization, Translation, and Citation will soon be supported by Microsoft Copilot and Microsoft 365 Copilot Chat in our menus
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/02/19
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=497135

ユーザーがブラウザーでコンテンツを強調表示した Edge のメニューは、Microsoft Copilot および Microsoft 365 Copilot Chat による要約、翻訳、引用をまもなくサポートする予定です。
