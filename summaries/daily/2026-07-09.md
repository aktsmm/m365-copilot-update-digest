### 政府機関向けクラウドのプロンプトを保護するための Microsoft 365 Copilot のデータ損失防止

- 原題: Microsoft Purview: Data Loss Prevention for Microsoft 365 Copilot to safeguard prompts for government clouds
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/07/09
- リリース段階: Rolling out
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=561892

機密データを含むプロンプトを保護するために、Microsoft Purview DLP for Microsoft 365 Copilot を拡張しています。このリアルタイム制御は、プロンプトに機密データが含まれている場合やプロンプトにプロンプトが含まれている場合に Microsoft 365 Copilot とエージェントが応答を返さないようにすることで、組織がデータ漏洩と過剰共有のリスクを軽減するのに役立ちます。
