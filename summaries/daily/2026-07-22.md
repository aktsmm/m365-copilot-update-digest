## 全件

### シームレスな検索とチャットの統合

- 原題: Microsoft Copilot (Microsoft 365): Seamless Search and Chat Integration
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/07/22
- リリース段階: Launched
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=512429

Microsoft 365 Chat は、会話型 AI のパワーを Microsoft 365 Copilot Search に直接導入し、ユーザーが情報の検索からそれに基づいた行動に簡単に移行できるようにします。検索結果は状況に応じたチャットの基盤となり、フォローアップの質問をしたり、洞察を総合したり、コンテンツを生成したりすることができます。

### Copilot Search 利用時に Copilot Chat を利用可能に

- 原題: Microsoft Copilot (Microsoft 365): [Copilot Search] [Copilot Search] Copilot Chat available when using Copilot Search
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/07/22
- リリース段階: Launched
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=537281

Microsoft 365 Copilot ユーザーは、Microsoft 365 Copilot アプリで Copilot Search を使用するときに、右側のサイド ウィンドウから Copilot チャットを利用できるようになります。これにより、ユーザーはページを切り替えたりコンテキストを失ったりすることなく、ユニバーサル検索を閲覧しながら Copilot を利用できるようになります。

### Viva Engage - コミュニティのエージェント

- 原題: Microsoft Copilot (Microsoft 365): Viva Engage - Agents in communities
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/07/22
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=499898

Viva Engage コミュニティのエージェントは、質問に答え、知識の共有を促進し、情報源を引用し、専門知識を拡張することでコミュニティをサポートします。
