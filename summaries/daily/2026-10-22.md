## 全件

### 販売開発エージェントが利用可能になりました

- 原題: Microsoft Copilot (Microsoft 365): Sales Development Agent is now available
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/10/22
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=573700

調査、評価、潜在顧客との関わりを行い、販売能力を 24 時間 365 日体制で拡張する自律的なエージェント。

### Microsoft Cowork で Planner のプラン・タスク管理に対応

- 原題: Planner: Capabilities in Microsoft Cowork
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/10/22
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=567315

Microsoft Planner を Microsoft Cowork に間もなく導入できるようになります。 Cowork では、アプリを切り替えることなく、計画、バケット、目標、タスクを表示、作成、更新できます。 Cowork は、ドラフトやメールの送信など、Microsoft 365 全体で Planner タスクの実行を支援することでさらに一歩進んでいます。

### IT 管理者が通話の録音と文字起こしのためにユーザー通知メッセージをカスタマイズできる機能

- 原題: Microsoft Teams: Ability for IT admins to customize the user notification messages for recording and transcription in calls
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/10/22
- リリース段階: Launched
- 役割タグ: 管理者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=567302

この機能を使用すると、IT 管理者は、Teams 通話中の録音と文字起こしのためにユーザー通知メッセージの一部をカスタマイズできます。

### Teams Rooms on Windows の対面会議で Facilitator の AI メモに対応

- 原題: Microsoft Teams: AI-powered notes for in-person meetings with Facilitator in Teams Rooms on Windows
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/10/22
- リリース段階: Rolling out
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=560318

Teams Rooms on Windows の対面会議で Facilitator をワンタップで招待し、会議のメモ、意思決定、アクション項目を AI で記録できます。生成したメモは会議室の前面ディスプレイに表示されます。
