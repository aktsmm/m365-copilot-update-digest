## 全件

### Microsoft Purview の連携機能を拡張

- 原題: Microsoft Purview: Compliance Manager-Purview Compliance Manager integration with Microsoft Foundry for automated mapping of AI regulations and evaluation of Compliance controls for Foundry Agents
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/27
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=536576

Purview Compliance Manager のこの機能により、顧客は AI Foundry で作成されたエージェントのコンプライアンス体制に自動的にアクセスできるようになります。お客様は、AI Foundry で作成されているエージェントを Purview Compliance Manager のコンプライアンス規制と評価にマッピングし、コンプライアンスのステータスを把握して改善を図ることができます。

### Copilot Studio でのコネクタの会話型構成

- 原題: Microsoft Copilot Studio: Conversational configuration of connectors in Copilot Studio
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/27
- リリース段階: In development
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=569930

完全な設定エクスペリエンスではなく、単純なチャット内サインインを使用して、エージェントが必要とするコネクタを構成します。

### ファシリテーターが質問を検出して回答します

- 原題: Microsoft Teams: Facilitator detects and answers questions
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/27
- リリース段階: In development
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=558341

ファシリテーターは、Teams 会議中に出された未解決の質問を自動的に検出し、Web 検索を使用して回答を提供するようになりました。参加者が質問 (例: 「LLM とは何ですか?」) をしても誰も答えない場合、ファシリテーターは答えを見つけるためのプロンプトを投稿します。参加者は「はい」を選択すると、エージェントに撤回してもらうことができます。

### Copilot ダッシュボードのインテリジェントな概要

- 原題: Microsoft Copilot (Microsoft 365): Intelligent Summaries in Copilot Dashboard
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/27
- リリース段階: Rolling out
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=557681

Copilot ダッシュボードのインテリジェントな概要を使用して、何が機能しているのか、どこに的を絞った注意が Copilot の導入を促進できるのかをすぐに明らかにします。インテリジェントな概要は主要な導入傾向を強調し、成功分野に焦点を当てます。提案されたプロンプトにより、根本的な傾向と推進要因をより深く調査できます。
