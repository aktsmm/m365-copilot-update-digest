## 全件

### Copilot Analytics - Cowork と WorkIQ の支出と使用状況に関する洞察

- 原題: Microsoft Viva: Copilot Analytics - Insights in Cowork and WorkIQ spend and usage
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/07/14
- リリース段階: Launched
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=566302

グループまたはチーム レベルでの AI 支出 (Copilot クレジットの使用量) に関する洞察は、ダッシュボードとしての Viva Insights および Advanced Insights で利用できるようになります。このリリースの対象となるサービスは、Cowork および Work IQ API です。ダッシュボード エクスペリエンスは、少なくとも 5 人の直属の部下 (範囲限定アクセス) を持つマネージャーが利用できます。

- 原題: Microsoft Purview: eDiscovery – Enhancement of Loop and Copilot Pages in Review and Export
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/07/14
- リリース段階: Launched
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=561492

レビュー セット内のキーワード検索のためのページ コンテンツの完全なインデックス作成を有効にし、検索からのエクスポートに対する HTML 形式のサポートを追加することにより、ループ ページと Copilot ページの電子情報開示ワークフローが改善されます。

### Copilot Chat で PDF・画像内テキストの検索精度を向上

- 原題: Microsoft Copilot (Microsoft 365): Copilot Chat can now better match search results from Scanned PDFs and from text inside images embedded in Word, Excel, and PowerPoint
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/07/14
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=559613

Copilot Chat は、スキャンした PDF からの検索結果や、Word、Excel、PowerPoint ファイルに埋め込まれた画像内に表示されるテキスト (Word でスキャンした契約書、Excel で表のスクリーンショット、PowerPoint でホワイトボードの写真など) の検索結果との一致を改善できるようになりました。これまでは検索や検索が困難でした。
