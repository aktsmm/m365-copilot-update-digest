## 全件

### Microsoft Copilot Studio: コンピューターの使用でワークフローを強化します

- 原題: Microsoft Copilot Studio: Supercharge your workflows with computer use
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/10/27
- リリース段階: Retirement
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=562220

コンピューター操作ツールを使って、回復性の高い AI ベースの UI 自動化をワークフローに直接組み込めます。作成者は、Web サイトやアプリの変更に合わせて動的に動く再利用可能な目標指向型の自動化を構築できます。管理者はアクセス制御、ホストされたブラウザーの管理、環境レベルの権限でガバナンスを維持できます。

### エージェント ノードを使用してエージェントをワークフロー ステップとして呼び出す

- 原題: Microsoft Copilot Studio: Invoke agents as workflow steps with the agent node
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/10/27
- リリース段階: Launched
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=566998

エージェント ノードを使うと、推論をワークフローに直接組み込めます。手動の引き継ぎを減らし、処理を高速化するとともに、追加開発なしで複雑な判断を伴うワークフローを実行できます。これにより、エンドツーエンドの業務をさらに自動化し、運用負荷を軽減できます。

### フォームを使用した構造化ドキュメントの生成

- 原題: Microsoft Copilot (Microsoft 365): Structured Document Generation with Forms
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/10/27
- リリース段階: Launched
- 役割タグ: 管理者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=545896

フォームを使用した構造化ドキュメントの生成により、組織は、SharePoint に組み込まれたガバナンスとコンプライアンスを使用して、大規模な標準化されたドキュメントを作成、管理、生成できます。ビジネス プロセスの所有者は、契約書、同意書、提案書、人事などのフォームベースのテンプレートを一元的に構築および維持できます。

### Microsoft Copilot でのセッションと応答の共有

- 原題: Microsoft Copilot (Microsoft 365): Session and Response Sharing in M365 Copilot
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/10/27
- リリース段階: Launched
- 役割タグ: 管理者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=562353

セッションと応答の共有により、Microsoft 365 Copilot のチャット内容をリンクで共有できます。セッション共有ではチャット全体を、応答共有では個別の応答を共有します。共有先では読み取り専用で表示され、受信者は自身の Copilot チャットで続けられます。

- 原題: Microsoft Copilot (Microsoft 365): SharePoint Site Builder
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/10/27
- リリース段階: In development
- 役割タグ: 作成者向け
