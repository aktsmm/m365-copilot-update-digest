## 全件

### Microsoft 365 Copilot の連携機能を拡張

- 原題: Microsoft Copilot (Microsoft 365): [Copilot Extensibility] Customers can connect M365 Copilot with Freshservice to access IT service documentation with Copilot Connector
- ソース: Microsoft 365 Roadmap
- 公開日: 2025/12/24
- リリース段階: Launched
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=513280

お客様は Microsoft Copilot を Fresh サービスに接続し、Copilot Connector を使用して IT サービス ドキュメントにアクセスできます。

### Copilot Studio エージェント ビルダーでのより大きなファイルのアップロードのサポート

- 原題: Microsoft Copilot (Microsoft 365): Larger file upload support in Copilot Studio agent builder
- ソース: Microsoft 365 Roadmap
- 公開日: 2025/12/24
- リリース段階: Launched
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=500375

Microsoft 365 の Copilot Studio エージェント ビルダーは、最大 512 MB のより大きなファイルのアップロードをサポートします。

### Microsoft 365 Copilot の会議・チャット機能を更新

- 原題: Microsoft Copilot (Microsoft 365): [Copilot Chat] Updated UI for Microsoft Copilot Navigation Pane in Word, Excel, PowerPoint, OneNote, Outlook, and Teams
- ソース: Microsoft 365 Roadmap
- 公開日: 2025/12/24
- リリース段階: Launched
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=516570

Copilot チャット ナビゲーション ペインを更新して、エージェント リストを簡素化し、表示されるチャット履歴リストをユーザーの最近 5 件のチャットよりも増やし、より目立つチャット履歴検索を追加しています...

### Copilot API TypeScript クライアント ライブラリ

- 原題: Microsoft Copilot (Microsoft 365): Copilot APIs TypeScript Client Libraries
- ソース: Microsoft 365 Roadmap
- 公開日: 2025/12/24
- リリース段階: Launched
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=501574

開発者: プロ開発者は、JS SDK を使用して CCS API を呼び出すことができます。
