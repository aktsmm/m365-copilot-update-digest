## 全件

### 新規作成した宣言型エージェントで、参照したスキャン済み PDF を理解可能に

- 原題: Microsoft Copilot (Microsoft 365): Newly created Declarative Agents now understand referenced scanned PDFs
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/26
- リリース段階: Launched
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=550514

新規作成した宣言型エージェントが、SharePoint で参照するスキャン済み PDF や画像ベースのドキュメントを根拠として、信頼性の高い回答を生成できるようになります。これまでエージェント シナリオで扱いにくかった主要なエンタープライズ コンテンツを活用できます。

### Copilot ノートブックで Power BI レポートを参照可能に

- 原題: Microsoft Copilot (Microsoft 365): Power BI reports as references in Copilot Notebooks
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/26
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=569928

Copilot ノートブックで Power BI レポートを参照として追加できるようになります。レポート データをファイルと共に取り込み、組織データに基づくより関連性の高い要約、プレゼンテーション、ブリーフの生成に活用できます。
