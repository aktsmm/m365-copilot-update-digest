## 全件

### 新しく作成された宣言型エージェントが、参照されたスキャンされた PDF を理解できるようになりました。

- 原題: Microsoft Copilot (Microsoft 365): Newly created Declarative Agents now understand referenced scanned PDFs
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/26
- リリース段階: Launched
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=550514

新しく作成された宣言型エージェントは、スキャンされた PDF や SharePoint から参照される画像ベースのドキュメントに確実に答えを抽出できるようになり、これまでエージェント シナリオでは使用が困難であった主要なクラスのエンタープライズ コンテンツのロックを解除できるようになりました。

### Copilot ノートブック の参照としての Power BI レポート

- 原題: Microsoft Copilot (Microsoft 365): Power BI reports as references in Copilot Notebooks
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/26
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=569928

Copilot ノートブック では、ユーザーが Power BI レポートを参照として追加できるようになり、レポート データをファイルと一緒にノートブックに直接取り込むことができます。 Copilot は、この情報を使用して、組織のデータに基づいた、より関連性の高い概要、プレゼンテーション、概要を生成します。
