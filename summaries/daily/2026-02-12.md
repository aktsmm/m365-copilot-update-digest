## 全件

### Microsoft 365 Copilot の会議・チャット機能を更新

- 原題: Microsoft Copilot (Microsoft 365): [Copilot Chat] Agent Mode in Excel
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/02/12
- リリース段階: Launched
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=543242

Microsoft 365 Copilot ライセンスを持たない Microsoft 365 サブスクライバーが利用できます。エージェント モードは、Web、Windows、Mac 用 Excel の Copilot にリリースされ、ユーザーはマルチステップ ワークフローを使用して Copilot でワークブックを構築および編集できるようになります。予算を更新したり、財務モデルを作成したり、データを分析したりするとき...

### 既存の ServiceNow ナレッジおよびカタログ接続の権限読み取りオプションを選択するための編集機能

- 原題: Microsoft Copilot (Microsoft 365): Edit capability for selecting permission reading option for existing ServiceNow Knowledge & Catalog Connections
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/02/12
- リリース段階: Launched
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=505438

以前の管理者は、編集機能がなかったため、ServiceNow ナレッジおよびカタログ Copilot コネクタの階層アクセス許可を適用するために新しい接続を作成する必要がありました。現在、管理者は既存の接続を簡単に編集して、アクセス許可処理オプション (シンプルとアドバンス) をすばやく切り替えることができます。

### People Skills - E3/E5 ユーザー向けに拡張された AI 推論

- 原題: Microsoft Copilot (Microsoft 365): People Skills - Expanded AI inferencing for E3/E5 users
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/02/12
- リリース段階: Launched
- 役割タグ: 管理者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=548643

People Skills は、AI を利用したスキル推論を拡張し、Microsoft 365 E3 および E5 のライセンスを持つユーザーを含めるようにしました。以前は、AI を活用したスキル推論は、Microsoft 365 Copilot および Microsoft Viva のライセンスを持つユーザーのみが利用できました。このアップデートにより、管理者は AI を活用したスキル推論を有効にするオプションを利用できるようになります。

### 増分クロールでサポート許可の同期が失われる

- 原題: Microsoft Copilot (Microsoft 365): Support permission sync missed in incremental crawl
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/02/12
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=503570

以前は、アクセス許可は定期的なフル クロールでのみ同期されていました。通常、ほとんどのコネクタでは、デフォルトの頻度が 1 日でした。現在、増分的な方法でより頻繁に権限の同期を実行できるようになりました。

### Copilot Search は人々の発見に役立ちます

- 原題: Microsoft Copilot (Microsoft 365): Copilot Search Helps You Discover People
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/02/12
- リリース段階: Rolling out
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=555240

Copilot Search は、より広範な人々の検索クエリに対して一致する人々を返すことができるようになりました。連絡先となる既知の人物と新しい人物を発見、曖昧さを解消し、探索できるようにします。 「プロジェクト リーダーシップ」や「人工知能」などの特定のスキルを持つ人材を探している場合は、Copilot の検索が役に立ちます...
