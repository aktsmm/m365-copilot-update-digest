### 音声チャットはメモリを参照できます

- 原題: Microsoft Copilot (Microsoft 365): Voice chats can reference Memory
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/02/26
- リリース段階: Rolling out
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=523204

ユーザーが Microsoft Copilot 音声チャットを行っている間、Copilot はユーザーの個人設定にすでに保存されている既存のメモリを使用して応答できます。プライバシーへの配慮により、ユーザーはまだボイスチャットからの思い出を修正/編集できません。ボイスチャットでの Copilot の応答に使用できるすべてのメモリが表示されます...
