### Word での読み上げ中の Q&A に音声を使用する

- 原題: Microsoft Copilot (Microsoft 365): Use voice for Q&amp;A during Read Aloud in Word
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/06
- リリース段階: Launched
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=523205

Copilot を使用して、Word で読み上げをリアルタイムで行います。文書が読み上げられているときに、「これはどういう意味ですか?」など、声で質問することができます。または「このセクションを要約してください」—すぐに答えが得られます。手動で一時停止して検索する必要はありません。これにより、状況を把握でき、中断が減り、彼は...

### PowerPoint の Agent Mode で添付資料のスタイルを新規プレゼンテーションに適用可能に

- 原題: Microsoft Copilot (Microsoft 365): Reference an attached PowerPoint deck’s style when creating a new presentation with Agent Mode in PowerPoint
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/06
- リリース段階: Launched
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=555880

エージェント モードを使用して PowerPoint で Copilot でプレゼンテーションを作成する場合、既存の PowerPoint ファイルを参照できるため、Copilot はそのテーマとスタイルを新しいデッキに適用し、デザインの一貫性を保ちます。 2026 年 6 月 5 日更新: この機能はまだ開発中で、2026 年 6 月中旬に展開を開始する予定です。

### Microsoft Purview で外部 Web 検索向け DLP 保護を強化

- 原題: Microsoft Purview: Data Loss Prevention - Data Loss Prevention to safeguard sensitive information from external web search in Microsoft 365 Copilot and Copilot Chat
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/08/06
- リリース段階: Rolling out
- 役割タグ: 管理者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=565870

機密データを含む Web 検索を保護するために、Microsoft Purview DLP for Microsoft 365 Copilot を拡張しています。このリアルタイム制御は、Microsoft 365 Copilot および Copilot Chat が外部の Web 検索に機密データを使用することを防ぎ、組織がデータ漏洩と過剰共有のリスクを軽減するのに役立ちます。
