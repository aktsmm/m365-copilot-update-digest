### Microsoft 365 Copilot の更新

- 原題: Microsoft Copilot (Microsoft 365): Developers building agents in Azure AI Foundry can ground their agent in files stored in SharePoint
- ソース: Microsoft 365 Roadmap
- 公開日: 2025/02/06
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け

テナント グラフ グラウンディングは、SharePoint に保存されているファイルなど、Microsoft Graph からの関連情報をエージェントに提供します。この機能は、エージェントを構築する開発者が利用できるようになりました。
