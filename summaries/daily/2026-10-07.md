### 情報保護 - SharePoint および OneDrive の自動ラベル付けスケールの拡大

- 原題: Microsoft Purview: Information Protection - Auto-labeling scale increase for SharePoint and OneDrive
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/10/07
- リリース段階: Launched
- 役割タグ: 管理者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=567890

SharePoint および OneDrive の自動ラベル付けの最大容量を、テナントあたり 1 日あたり 100,000 ファイルから最大 500,000 ファイルに増加します。これにより、組織はより多くの保存データをより迅速にラベル付けして保護し、既存のコンテンツ間のラベル付けのギャップを埋めることができます。機密ラベルと保護設定を適用すると...

### Microsoft 365 Copilot アプリ (iOS) の Copilot ノートブックを刷新

- 原題: Microsoft 365 app: New Copilot Notebooks design in the Microsoft 365 Copilot App (iOS)
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/10/07
- リリース段階: Launched
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=566318

Microsoft 365 Copilot アプリ (iOS) の Copilot ノートブックを使用すると、ユーザーは関連するチャット、出力作成、参照を永続的な AI ワークスペースに整理できるようになりました。 Copilot はノートブックに蓄積されたコンテキストを使用して応答をグラウンディングするため、作業は毎回最初からやり直すのではなく、セッションをまたいで継続されます。

### Microsoft 365: OneDrive 用の従量課金制ストレージ

- 原題: Microsoft 365: Pay-as-you-go storage for OneDrive
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/10/07
- リリース段階: In development
- 役割タグ: 管理者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=562352

追加の OneDrive ストレージ用の新しい従量課金制の消費量ベースのメーター。どの OneDrive アカウントがライセンスされたストレージ制限を超えて拡張できるかを制御し、選択したユーザーに必要に応じて追加のスペースを提供します。

### Planner エージェントの AI 生成ステータス レポート

- 原題: Planner: AI-generated Status Reports in Planner Agent
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/10/07
- リリース段階: In development
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=567886

Planner Agent の AI を活用したステータス レポートは、計画データを数分で洗練された関係者向けの更新に変換します。 Planner Agent にステータス レポートを依頼するだけで、タスク データが取得され、全体的なステータス、進捗状況、リスク、および次のことをカバーする明確な説明に変換されます。簡単にカスタマイズできます...

### Copilot Analytics - Agent 365 ダッシュボードのエージェント価値に関する洞察

- 原題: Microsoft Viva: Copilot Analytics - Agent value insights in Agent 365 Dashboard
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/10/07
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=570847

お客様は、Microsoft Viva Insights (Copilot Analytics) の Agent 365 ダッシュボードで価値に関する洞察を表示できるようになりました。これらの洞察は、ビジネス リーダーや変更および導入のスペシャリストが、エージェントが使用されているかどうかだけでなく、エージェントが提供する推定支援時間や作業の種類についても理解するのに役立ちます。
