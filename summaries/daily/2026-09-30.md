## 全件

### 管理センターに GCC 向け Copilot Chat 使用状況レポートを追加

- 原題: Microsoft Copilot (Microsoft 365): Microsoft 365 admin center - Usage reports - Copilot Chat for GCC, GCC High and DoD
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/09/30
- リリース段階: Launched
- 役割タグ: 管理者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=567121

Copilot Chat をカバーする新しい使用状況レポートを導入します。このレポートには、アクティブ ユーザーの合計、Microsoft 365 アプリごとのブレイクアウトを含む Copilot Chat の使用状況、およびユーザー レベルのアクティビティに関する分析情報 (既定では匿名化されています) が含まれます。 #copilotcontrolsystem

### キュー アプリでの通話後に Copilot チャットを使用する

- 原題: Microsoft Teams: Use Copilot Chat after a call in Queues app
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/09/30
- リリース段階: Launched
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=568933

キュー アプリで録音済み通話後に Copilot Chat を使い、要点把握、洞察確認、顧客課題の解決を効率化できます。

### Excel エージェント

- 原題: Microsoft Copilot (Microsoft 365): Excel Agent
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/09/30
- リリース段階: Launched
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=543422

Excel Agent は、組み込みの数式とロジックを使用して、データを明確なグラフ、概要、洞察に変換します。データの準備、数式、視覚化を効率化し、数字の背後にあるストーリーに集中できます。マルチターン チャットで出力を調整したり、Excel で開いて編集したりできます。

### クイック コンポーザーを使用すると、Copilot のボイス チャットでライブ字幕が表示されます。

- 原題: Microsoft Copilot (Microsoft 365): Live subtitles on voice chat in Copilot when using the quick composer
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/09/30
- リリース段階: Launched
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=502858

Copilot のボイス チャットのライブ字幕は、ユーザーがクイック コンポーザーを使用するときに会話を理解するのに役立ちます。

### スキル カタログからスキルを検出して追加

- 原題: Microsoft Copilot Studio: Discover & Add Skills from the skill catalog
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/09/30
- リリース段階: In development
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=571880

Copilot Studio のスキル カタログを使用すると、メーカーはエージェントごとに同じ指示やワークフローを再作成するのではなく、承認された組織スキルを発見、再利用、選択的に共有できます。 Microsoft 365 App Store を利用した共有カタログにより、共有スキルを次のようなエクスペリエンスに拡張できます。

### Copilot Analytics - エージェント ダッシュボードからのメトリクスのエクスポート

- 原題: Microsoft Viva: Copilot Analytics - Export metrics from Agent Dashboard
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/09/30
- リリース段階: In development
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=560538

ユーザーは、匿名化された行レベルのエージェントのメトリクスと属性をエージェント ダッシュボードからエクスポートできます。エクスポートされたデータは、個人識別情報が削除された状態で、組織全体にわたるエージェントの使用状況とユーザーレベルのエージェントのやり取りに関する詳細な洞察を提供します。 #copilotcontrolsystem
