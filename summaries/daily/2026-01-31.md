## 全件

### Designer は Copilot の一部となり、新しいテンプレートとスライドの提案で強化されました。

- 原題: PowerPoint: Designer is now part of Copilot, enhanced with new template and slide Suggestions.
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/01/31
- リリース段階: Launched
- 役割タグ: 管理者向け / 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=483882

デザイナーは現在 Copilot の一員です。 Copilot Suggestions では、使い慣れた Designer のスライド レイアウトとプレゼンテーション テンプレートの提案が垂直ギャラリーに表示されるほか、新機能も追加されました。

### Copilot Tuning を使用して組織に合わせて Microsoft Copilot をカスタマイズします

- 原題: Microsoft Copilot (Microsoft 365): Customize M365 Copilot for your organization with Copilot Tuning
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/01/31
- リリース段階: In development
- 役割タグ: 作成者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=552589

Microsoft 365 Copilot Tuning では、Agent Builder に新しいテンプレートが導入されています。このテンプレートは、複雑なドキュメントの作成、ガイドラインに照らしたドキュメントの検証、および相違点に一致する編集などのタスク向けに設計されています。

### IT 管理者が記録および文字起こし用のユーザー通知文字列をカスタマイズできる機能

- 原題: Microsoft Teams: Ability for IT admins to customize the user notification strings for recording and transcription
- ソース: Microsoft 365 Roadmap
- 公開日: 2026/01/31
- リリース段階: Launched
- 役割タグ: 管理者向け
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=536570

IT 管理者は、会議中の録音や文字起こしの使用について暗黙的に通知したり、会議参加者から明示的な同意を得るために使用されるメッセージとプライバシー リンクをカスタマイズできます。
