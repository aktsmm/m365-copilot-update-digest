### Microsoft 365 Copilot による機密ラベル付きコンテンツの処理を防止するデータ損失防止は、すべての保存場所をサポートします
- ソース: Microsoft 365 Roadmap
- 領域: Microsoft Purview
- 公開日: 2026/07/18
- なぜ重要か: 提供開始済みで利用可否の確認に直結するため / 管理やガバナンスへの影響が大きいため
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=557255
Word、Excel、PowerPoint の機密ファイルの処理を Microsoft 365 Copilot で制限する Microsoft Purview データ損失防止ポリシーが、ファイルの保存場所に関係なく適用されるようになりました。
### 情報保護 - SharePoint および OneDrive の自動ラベル付けスケールの拡大
- ソース: Microsoft 365 Roadmap
- 領域: Microsoft Purview
- 公開日: 2026/07/18
- なぜ重要か: 今後の展開計画や事前準備に影響するため / コスト配分や予算管理の見直しに直結するため
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=567890
SharePoint および OneDrive の自動ラベル付けの最大容量を、テナントあたり 1 日あたり 100,000 ファイルから最大 500,000 ファイルに増加します。これにより、組織はより多くの保存データをより迅速にラベル付けして保護し、既存のコンテンツ間のラベル付けのギャップを埋めることができます。機密ラベルと保護設定を適用すると...
### プランナー: Microsoft Cowork の機能
- ソース: Microsoft 365 Roadmap
- 領域: Planner
- 公開日: 2026/07/18
- なぜ重要か: 今後の展開計画や事前準備に影響するため / ライセンス設計や展開判断に直結するため
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=567315
Microsoft Planner を Microsoft Cowork に間もなく導入できるようになります。 Cowork では、アプリを切り替えることなく、計画、バケット、目標、タスクを表示、作成、更新できます。 Cowork はさらに一歩進んで、メールの下書きや送信、スケジュール設定など、Microsoft 365 全体で Planner タスクの実行を支援します。
### Microsoft 365 Copilot の会議・チャット機能を更新
- ソース: Microsoft 365 Roadmap
- 領域: Microsoft 365 Copilot
- 公開日: 2026/07/18
- なぜ重要か: 今後の展開計画や事前準備に影響するため / 管理やガバナンスへの影響が大きいため
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=567670
Agents 365 に公開されたエージェントは、Microsoft 365 管理センターですでに管理されています。エージェントが Agent2Agent プロトコルを実装している場合、ユーザーが Agent Builder または Copilot Studio で構築するエージェントの接続エージェントとして使用できます。
### Microsoft Purview の会議・チャット機能を更新
- ソース: Microsoft 365 Roadmap
- 領域: Microsoft Purview
- 公開日: 2026/07/18
- なぜ重要か: 今後の展開計画や事前準備に影響するため / 管理やガバナンスへの影響が大きいため
- URL: https://www.microsoft.com/microsoft-365/roadmap?id=565870
Microsoft は、機密データを含む Web 検索を保護するために、Microsoft 365 Copilot および Copilot Chat 用の Microsoft Purview DLP を拡張しています。このリアルタイム制御は、Microsoft 365 Copilot と Copilot Chat が外部の Web サイトに機密データを使用することを防ぎ、組織がデータ漏洩と過剰共有のリスクを軽減するのに役立ちます。
